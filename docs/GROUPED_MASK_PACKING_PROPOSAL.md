# 提案: グループ付き資源割当のビットマスクDP

[`grouped_mask_packing`](../library/grouped-mask-packing.hpp) は、互いに共有できない
資源が少数あるとき、各グループから高々一つの候補を選び、価値の合計を厳密に最大化
します。一つの候補が一人を使う場合も、同時に二人以上を必要とする場合も扱えます。
通常の二部マッチングとは異なり、一つの作業を複数の人にまとめて割り当てられます。

```cpp
const auto plan = ahc::grouped_mask_packing(worker_count, candidates_by_job);
for (std::size_t j = 0; j < plan.option.size(); ++j) {
  if (plan.option[j] >= 0) { /* j 番目の作業に選ばれた候補を使う */ }
}
```

資源は最大16個。候補には資源マスクと `int64_t` の価値を持たせます。
グループのスキップは常に可能で、非正の候補は採用しません。資源を使わない
候補や同一マスクの候補も指定できます。結果には合計値・使った資源・各グループの
候補番号が入ります。同点の解の選び方には依存しないでください。

資源数を R、グループ数を G、候補総数を K とすると、時間 O((G+K)2^R)、
領域 O((G+1)2^R) です。復元不要・グループが独立・各候補が一資源しか使わない
場合は、その条件に合わせたより軽い割当手法を選ぶ余地があります。

AHC008 では、各捕獲区画をグループとし、片端を一人で閉じる候補と両端を二人で
閉じる候補を同じ問題として扱います。捕獲候補の価値は別に評価します。
AHC008 専用の実装を公式配布100ケースで比較したところ、全頭捕獲100/100のまま、
対象19件で4マス以内の区画に捕獲できた頭数は134→141。合計得点は333,335点
下がり、提出版には採用していません。この独立ヘッダの速度を示す値ではありません。

[使用例](../examples/grouped_mask_packing_usage.cpp) は三人の作業で最適値17を出力します。
[テスト](../tests/grouped_mask_packing_test.cpp) は全候補列挙と照合し、重複資源、
0資源、16資源の境界、値のオーバーフロー、復元した割当も検査します。

GNU C++23、警告をエラー扱いにしたビルドと UBSan で、全列挙との比較5,500例が通りました。
