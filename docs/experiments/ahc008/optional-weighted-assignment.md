# 省略可能な重み付き割当のAPI提案

AHC008 v25の通路内待機では、少数の担当者と多数の動物の間で、到達できる組だけを使い、一人と一頭をそれぞれ高々一回割り当てる。割当不要なら見送る。別通路の同じ動物は独立した問題として扱う。この用途のために問題側で小人数ビットDPと復元処理を実装した。

新しいアルゴリズムは提案しない。研究枝の長方形 Hungarian `hungarian_rectangular_minimum_assignment` を流用し、各担当者専用の評価0のダミー枠を入れて、未割当を `-1` で返す薄いAPIを検討する。禁止辺と重み0の辺を区別する。数字の大きい番兵で禁止辺を表す場合は内部演算のオーバーフロー条件を明記し、負の重みを無理に割り当てない。重み0のダミーとの同点は決定的に処理し、方針を明記する。小人数では現行のビットDPや既存の MinCostFlow が引き続き候補。

例: `{{8, nullopt, 2}, {4, 7, nullopt}}` なら仕事0と1で計15。全て禁止、一部のみ許可、空入力、負の重み、同点、極端な値をテストし、小さい疎行列では全列挙、もう少し大きいものでは MinCostFlow と照合する。速度は担当者5〜10人・仕事10〜30件の疎行列について割当生成費用も含めて逐次比較する。高速化の主張・既存ライブラリへの変更はまだなし。
