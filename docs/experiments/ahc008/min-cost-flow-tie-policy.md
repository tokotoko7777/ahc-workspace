# 最小費用流の同点順序を選べるようにする提案

- 問題: AHC008。元の手順を再現する際、割当の最大流量・総費用は同じでも、同点時に別の動物へ人が動いた。今の `library/min-cost-flow.hpp` は同費用の候補を頂点番号が小さい順に取り、比較対象の手順は大きい順で、終点が確定したときに探索を打ち切る。これにより、その後の人と動物の軌跡は変わる。既存ライブラリの解の正しさに問題があるわけではない。
- 例: 一人が同じ列にいる上下等距離の動物のどちらかへ向かう。総費用は同じでも、上へ行くか下へ行くかが逆になる。複数割当では先の選択の残余辺も後の同点に影響する。
- 回避: AHC008の再現用に独立した専用実装を使った。[実装アーカイブと採点](https://github.com/tokotoko7777/ahc-workspace/blob/8e657891bf5181216e2ec66f4aca47a1cc54166d/problems/ahc008/experiments/20261122/article-capture/terry-faithful-cpp/README.md) の `ahc008_terry_exact_ties/`。同点割当の例、残余辺での組み替え、1,200個の小規模全探索との最大流量・最小費用比較を検証。
- 提案: 再現性が必要な場合に限って、キューの第2キー（小さい頂点優先／大きい頂点優先）と終点確定時の停止を明示できる補助APIを検討する。同距離の先行辺を置換しないこと・辺追加順・残余辺の扱いを文書化する。既定は変えない。終点で打ち切る実装では、その反復で確定した頂点だけを正しいポテンシャル式で更新し、既存テストに加え、同費用時の選択結果とランダム小規模の費用・流量を別々に検証する。
- 対応状況: 提案のみ。汎用ライブラリは変更していない。
