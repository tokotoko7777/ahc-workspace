# 近傍グラフ上の短い確率伝播（提案）

AHC008の捕獲候補評価では、全探索の経路列挙もモンテカルロ予測の誤差も避けたい。均等確率で進む局所グラフなら、正の出次数の最小公倍数を分母として、整数質量を短いステップだけ伝播できる。4近傍では分母12、0近傍はその場に留まる。実験は最大9歩で共通分母12^9。セルID順ではなく質量が非ゼロのセルだけ次層と消去に回す。入口から出て戻る経路も数える。[実際の利用・検証と小さな実装](https://github.com/tokotoko7777/ahc-workspace/blob/08f71a465a41b0005a4ad0f9bcb674d93588d008/problems/ahc008/experiments/20261122/article-capture/terry-passive-exact-short/VALIDATION.md)。

- API案: 隣接リスト、開始点または初期質量、出次数の公倍数、観測ステップを渡し、各時刻の対象集合の整数質量と分母を受け取る。出次数・整数の乗算上限・同時に合算する質量の上限は明示して検査する。
- 利用例: 一本道の中央から1歩後に中央に残る質量は0、2歩で両端が行き止まりなら1。隣接ゼロのセルでは全時刻1。
- テスト: 上記のほか、入室後の退出と再入室、各層の総質量保存、複数の観測時刻、短いランダムグラフの経路全列挙との比較。支持集合の上限やオーバーフローもテストする。
- 現状は問題内の実験でのみ実装。30×30のサイズや局所支持集合の上限は汎用版に持ち込まない。移動中に壁が変わる、行動が一様でない、観測が長い場合はこの提案をそのまま流用しない。共通ライブラリ本体は変更していない。
