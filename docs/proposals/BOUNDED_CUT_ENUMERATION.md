# BFSの経路を使った頂点カット1〜2枚の列挙

**状態:** AHC008の事後診断で試作・検証済み。オンライン探索の速度は未評価なので、まだライブラリ本体には入れない。

## 欲しかった処理

グリッド上の既存壁・配置禁止セルを固定し、基点側に全作業者と最低面積を残しつつ、対象を分離する追加壁を1〜2枚列挙する。面積だけでなく、分離した対象の集合と区画サイズも返す。配置禁止とグラフを取り除く壁の状態は別に与える。

## 候補生成の根拠

1. 対象と基点を結ぶ経路をBFSで1本得る。対象を分離する頂点集合は必ずその経路と交差する。
2. その経路上で配置可能な点を1つ除く。まだつながっていたら、残った経路上で配置可能な点だけが2枚目になり得る。既に切断できたなら1枚案を記録する。
3. 非最小の2枚案も必要なら、1枚で分離できる全候補に合法な2枚目を追加する。別の対象も分離したり、分離済み区画を小さくしたりできる。1枚案で残留面積がちょうど下限でも、2枚目が保持領域の外なら面積を維持できる。下限未満・基点側の人が分断済みなら壁を増やしても直らない。
4. 順不同の組を重複排除し、連結成分と面積を検証する。担当者が届くか、先に置けるか、動く対象が残るか、は呼び出し側の問題として分離する。

単独対象で頂点数をV、辺数をE、経路長をLとすると、1枚目の候補生成は最大O(L×(V+E))。候補ごとの連結成分検査は別で、グラフ・合法セル数によっては結局二次個の組を返す。全列挙が必要な診断向け。オンラインでは候補を制限した版や BFS 訪問配列の使い回しが必要。

## 検証と使いどころ

- 5×5のランダム連結盤面971件。基点側の最低面積は3。配置可能な点を1つまたは2つ選ぶ全探索と、全1,569候補の組・捕獲数・未捕獲数・4マス以下判定・残留面積が一致。
- 境界条件として、最低面積ちょうどを保った非最小2枚案、初期面積が下限+2のときに壁1枚と対象1マスを切り離せる案を明示的に扱う。
- AHC008: 4本通路型の捕獲失敗10件で、柵を置ける形が盤面にないのか、そこに人が来ていないのかを切り分けるのに使用。[研究経過](../AHC_PROGRESS.md) 参照。リプレイの候補抽出であり、事前予測で得られる結果ではない。
