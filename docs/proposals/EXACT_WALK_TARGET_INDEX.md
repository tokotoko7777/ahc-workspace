# 同じ目的地への「ちょうど k 歩」を使い回す

[実装](../../library/exact-walk-target-index.hpp) /
[使用例](../../examples/exact_walk_target_index_usage.cpp) /
[層DPとの比較](../../tests/exact_walk_target_index_test.cpp)

壁も目的地の集合も同じで、始点と歩数を変えて何度も問い合わせる場合の部品。無向グラフ上で歩数の偶奇を状態に足し、目的地集合から逆向きにBFSする。指定された偶奇の最短距離が k 以下なら、余った偶数歩は開いている辺の往復で埋められる。閉じたマスと孤立点は別扱いし、孤立点だけ静止できるモデルを指定可能。自己ループや奇数サイクルを含む無向グラフでも使える。

構築 O(V+E)、問い合わせ O(1)。壁・辺・目的地を変えたら作り直す。辺が片方向の場合や、ターンによって移動規則が変わる場合は対象外。[exact-step-frontier](EXACT_STEP_FRONTIER.md) は、各長さで到達できる全頂点が必要な場合や有向グラフで使う。短い数歩の問い合わせが少数だけなら、局所的な層DPの方が軽いこともある。

AHC008 では一口の区画で、動物が外から柵を合法に閉じられる内側まで届くかの切り分けに利用できる。入口とその隣は終点にできないので、外側からは最低3歩。これは現在の柵と到達性だけの判定で、来訪確率・他の動物による閉鎖妨害・実際の捕獲を保証しない。実行版への採用・得点向上とは区別する。

テストは4,800個の乱択無向グラフで全始点、0〜24歩、孤立頂点の静止あり／なしを愚直な層DPと比較。
