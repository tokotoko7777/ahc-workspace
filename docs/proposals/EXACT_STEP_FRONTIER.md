# ちょうど指定歩数で到達できる頂点

[ヘッダー](../../library/exact-step-frontier.hpp) /
[短い例](../../examples/exact_step_frontier_usage.cpp) /
[愚直DPとの比較テスト](../../tests/exact_step_frontier_test.cpp)

残りの移動が「高々2歩」ではなく「必ず2歩」なら、格子の偶奇によって終点集合が異なる。移動回数だけ層を進め、必要な層の頂点集合だけを合併する。隣接表・壁・始点集合・許容する歩数のビット集合を渡す。頂点で足止めされる場合のみ留まれるモデルも選べる。

例えば直線 `0–1–2–3` で0からちょうど2歩なら、到達は0と2の2点だけ。1歩または2歩の両方を許すには `(1u<<1) | (1u<<2)` を渡す。9頂点のランダム有向グラフ7,000件で、層ごとの愚直DPと照合した。

AHC008では、両端を1マス内側へずらして閉じる試作の「フェンスを置く次ターンの、全動物の終点の上界」に適用した。猫と豚は2歩、犬は保守的に1歩と2歩の両方で評価する。どの終点も次の柵やその隣に来ず、今回捕まえる対象が全て予定区画に残るかを別途確認する。目的地の推定確率は使わない。次ターンの幾何を守るだけで、将来の割当・全頭捕獲・最終共有地までは保証しない。
