# 局所パッチの外周間距離を比較する

[実装](../../library/boundary-transit.hpp)・[短い使用例](../../examples/boundary_transit_usage.cpp)・[差分テスト](../../tests/test_boundary_transit.cpp)。

## 何を保証するか

固定の無向・単位コストグラフの一部を「内部」として、一辺で接する外部頂点を「出入口」とする。各出入口の組について、他の外部頂点を経由せず内部だけを通る最短距離を記録する。内部を経る道がなければ `unreachable`。出入口同士の外部辺は元のグラフに残す。

内部部分の道は距離表の重み付き辺に置き換えられる。変更前後の表が同一なら、同じ外部の壁の下で、どの外部頂点対でも距離が等しい。出入口を外部の壁で閉じた場合は、その頂点と全ての接続辺を消す。表を再計算する必要はない。

内部への壁の追加だけなら、各距離は短くならない。開始時点と完成時点の表が一致すれば、完成形の壁を組み立てる途中の全段階でも表は一致する。これは**外同士の最短距離のみ**の保証で、内部への所要時間、同距離の経路候補、行動の優先順位、動物の移動は変わり得る。

## 使い方

同じ隣接関数で `ahc::BoundaryTransit<N> patch(interior, next)` を構築し、`patch.signature(before_walls, next) == patch.signature(after_walls, next)` を比較する。ネイバーの負数・範囲外IDは無視する。内部や出入口の番号を変えずに同じ差分を何度も照会できる。表の長さは出入口数 p に対して p(p−1)/2。小さいパッチと少数の出入口向けで、盤面全体への一律適用や速度改善は主張しない。

## AHC008での使用・テスト

三通路配置の一部を5～9マスから3～4マスへ狭める研究で、元の走路を保つ支え柵だけを抽出した。163候補に局所隔離・外側の担当位置を検査し、外周距離も同一の37候補を得た。実際に担当を置けるか、全頭捕獲と共有面積を維持できるか、は別判定。採用ソルバーの点数や速度の改善ではない。集計は [AHC008の進捗](../AHC_PROGRESS.md) に記録。

差分テストは1,250個の格子パッチで、重み付き辺に置き換えた外部の最短距離を愚直な盤面全体のBFSと2,237,076組比較。外部の出入口削除2,654件を含み、入れ子の壁に対する49,514組で単調性も確認した。
