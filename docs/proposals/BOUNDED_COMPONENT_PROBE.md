# 小さい連結成分だけを調べ、目的地がないことを証明する

毎回大域 BFS が必要とは限らない。障害物で囲われた小さな領域の始点から、
指定した上限までだけ探索する。最後まで調べても目的地がなければ
この始点と同じ領域の再試行を省ける。途中で目的地を発見、上限に到達、
始点が通行不能の場合は結果を分ける。上限到達を「目的地なし」とは扱わない。

- 実装: [bounded-component-probe.hpp](../../library/bounded-component-probe.hpp)
- 使用例: [bounded_component_probe.cpp](../../examples/bounded_component_probe.cpp)
- 検証: [test_bounded_component_probe.cpp](../../tests/test_bounded_component_probe.cpp)
- 目的地や壁の状態を変えたら、成功した探索を保存するビット集合を初期化する。
- AHC008: 終盤の仮想実行で、人がいない狭い区画の犬は元のコードと同じ
  単発のランダム移動になる。犬の状態・乱数消費を変えず、人ごとの
  大域距離計算を避ける。大区画や未確定時は従来処理へ戻る。

### AHC008での確認

手書き適用版では、GNU C++23単一ファイルの固定24組・同じ2,400msで、
配布100件・別生成100件の全操作と得点が従来と一致した。同時間に完了した
終盤の比較は配布1,485→1,830（+23.23%）、別生成1,844→2,329（+26.30%）。
この速度値は手書き版、公開ヘッダの正しさは別の33万照会で照合した。
未確定を否定扱いしないこと、および複数の初期点で認定済み集合を共有できる
ことを例に示した。[進捗・計測](../AHC_PROGRESS.md)
