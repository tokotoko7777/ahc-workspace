# 区画を広げないために残す柵を一度の探索で求める

[ヘッダー](../../library/protected-component-gates.hpp) /
[短い使用例](../../examples/protected_component_gates_usage.cpp) /
[全列挙テスト](../../tests/protected_component_gates_test.cpp)

同時に柵を閉めた直後のグラフで、いくつかの柵を取りやめても
保護対象（AHC008ならすでに捕獲した動物）の連結成分を広げないとする。
このとき、守るべき成分に隣接する候補柵だけが必須。
対象を始点とする多始点探索で、壁に当たるたびに候補なら印をつける。

**理由:** 必須の柵を1枚でも開ければ、そのセル自体が保護成分に入り、
面積が増える。逆に未印の柵をすべて開けても、保護成分から新しく
進める最初のセルが開くことはない。したがって各成分は変わらない。
人の位置を固定するなら、任意の柵を開けるほど到達域は増えるので、
未印の柵をすべて開けるのが人の面積を最大化する。
「対象を逃さなければ保護成分が広がってもよい」、移動も変更する、
あるいは後続ターンの動物の動きまで守る問題にはこの結論を広げない。

`required_component_gates` に隣接表、閉鎖セル、開放候補、保護する始点を渡す。
返値は残さなければならない候補柵の集合。候補数による指数時間は不要。
4×5盤面2,350件で、候補柵の全ての開け方と保護成分の一致を照合。

AHC008の配布100件で、未捕獲の動物も残る段階に捕獲を成功させつつ、
同時に柵を2枚以上（うち捕獲担当が1枚以上）置いた925場面を検証。
各場面で従来の部分集合全列挙と一致し、保護成分を変えずに外せる候補は0枚。
保護成分の広がりを許しても、捕獲対象を変えず共有地が増える候補は0。
全100件の行動と得点も一致。得点版への採用はしていない。
