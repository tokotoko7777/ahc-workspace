# 同時手で人側の連結領域を守れるか厳密に調べる

[実装](../../library/joint-separator-step.hpp)・[使用例](../../examples/joint-separator-step.cpp)・[総当たり比較](../../tests/joint-separator-step.cpp)

作業者が1手で「待機」「隣へ移動」「隣を塞ぐ」のいずれかを行えるとき、全員が同じ連結成分に入り、その成分に排除対象のマスが含まれない手のうち、共有面積最大のものを選ぶ。予定柵の部分集合だけを試す [到達集合を保つ切り方](PRESERVE_REACHABILITY.md) と異なり、出発位置から可能な柵への担当付けと移動を組み直す。

- 最大6人、最大次数4。人の同じマスへの移動は許し、同時に柵が置かれるマスへの移動は禁止。合法な柵のマスクは呼び出し元で作り、元の壁・人の出発位置・固有の禁止条件を除く。
- 各人の柵担当または非担当だけ先に列挙する（最多 `5^M`）。残りの人の移動は、候補の共通成分に現位置か1歩先があるかを見ればよい。新しい壁を置く人は移動しない。
- AHC008では、全頭捕獲の最後の柵で初めて人が分かれた少人数の5盤面を公式テスターで再生し、同じ合法条件で担当を丸ごと組み直せるか調査。全5件で同じターンに両立できる手はなかった。盤面あたり104〜2,628割り当て。得点版には導入せず、何ターン前から動く必要があるか判断するための診断に使用。
- 本番のホットループではなく、局面を絞った厳密解やデバッグ用を想定する。

```sh
g++ -std=gnu++23 -O2 examples/joint-separator-step.cpp -o /tmp/separator-example
/tmp/separator-example
g++ -std=gnu++23 -O2 tests/joint-separator-step.cpp -o /tmp/separator-test
/tmp/separator-test
```
