# 分離後の共有領域に対する上界

最小の柵枚数だけを評価すると、狭い通路1か所を切って広い領域ごと手放す案が選ばれる。マスを捨てる費用も含めた頂点カットで、指定した始点群をつなげたまま対象群を分離するときの共有領域の上界を求める。閉鎖が実現可能であることの証明ではない。

## 入力と構成

現在の一つの連結成分を `A`、残す始点群を `H`、分離する対象群を `P`、削除可能頂点を `D` とする。各頂点に非負の面積重みを与える。単位グリッドならすべて1。`INF` は全重みの和より大きな値にし、容量の型と上限に注意する。

1. 各頂点 `v` を `v_in, v_out` に分ける。 `v_in → v_out` は `v ∈ D` なら面積重み、そうでなければ `INF`。
2. `source → v_in` に面積重みを置く。無向の隣接には両方向の `v_out → u_in` を `INF` で置く。
3. `H` は `source → h_out`、`P` は `p_in → sink` を `INF` で結ぶ。始点と対象の同居はその場で分離不可。
4. 最小カットが `INF` なら、その時点・削除範囲・固定始点での分離は不可。それ以外では `全重み − 最小カット容量` が共有領域の上界。`in` のみ source 側に残る頂点が柵候補。

保証の理由は、実際の共有連結成分とそれを囲む合法な削除集合によって、整数面積がその成分と同じカットを構成できるため。逆向きは成り立たない。緩和は複数の始点が別々の成分に残る場合や、どの始点からも届かない領域を source 側に含める場合がある。

## 使い方

`if (bound < min_area) continue;` として枝を刈り、残りは柵候補を反映した盤面で BFS。始点群の同一連結成分、実面積、対象の区画サイズ、合法な柵か、担当の重複、移動と設置の順番を独立に確認する。「現在置ける全頂点」は楽観的な範囲であり、「担当者に隣接する合法頂点」から計算すると同じターンのさらに強い上界になる。動物や担当者が動いた後には再計算が必要。

## 検証と適用

- 3×4 の連結部分グリッド、始点1〜2、対象1〜2で、削除頂点の全列挙と比較。1,376組で正解を過小評価せず、有限解がある142組で上界は厳密でなかった。
- AHC008 終盤のリプレイでは、共有地528の時点の全頭閉鎖について「今の担当位置から置ける柵」に限った上界が400、実際の閉鎖後が399。担当の到達を無視した合法柵では上界511だった。柵の形と配置時間を切り分ける診断に使える。
