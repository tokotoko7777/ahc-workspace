# 全員の到着を待つ割当

[ヘッダー](../../library/small-bottleneck-assignment.hpp) /
[短い例](../../examples/small_bottleneck_assignment_usage.cpp) /
[全列挙との比較](../../tests/small_bottleneck_assignment_test.cpp)

少人数で複数の仕事を並行し、すべて揃ってから次へ進むときに使う。
各行を仕事、各列を担当者にした行優先の到着時刻を渡す。到達不能は
`-1`。全ての仕事を異なる人に割り当て、最後の到着を最速にする。
同じ時刻にそろう割当の中では、到着時刻の合計が最小のものを返す。
割当なしは `std::nullopt`。人は最大16人。時刻は非負 `int`、
合計は64ビット。

前半は使用済み担当者の集合ごとに最大時刻を最小化する。後半は
その最良の時間より遅い割当を除外し、同じ状態で合計を最小化する。
1回の辞書順DPでは不足する。例えば途中の（最大2、合計4）と
（最大3、合計3）に同じ4を足すと、先に捨ててしまった後者が最良。
実行時間 O(M×2^M)、使用メモリ O(2^M)。通常の最小費用割当や、
先着者が何度も別の仕事をするスケジューリングとは異なる。

AHC008では終盤の追い込みで、柵のマスそのものではなく、人の側から
閉められる隣の立ち位置までの実際の経路を使う。置ける柵を今すぐ
置く判断が既にある場合は変更せず、最も遅い担当の到着を厳密に
短縮できる移動だけを試す。この部品は動物の動きや、同時に閉める
こと自体を保証しない。小さい乱択15,000件の全割当列挙と照合し、
到達不能・空の入力・大きな時刻も検証済み。

問題側の固定長配列による割当と、このヘッダーの結果を、配布100件の350回の呼び出し（11盤面）で比較。最大時刻・合計・同点時の担当選択、100件の全行動と採点が一致した。比較用には汎用版も使い、計測用の組込み版は動的確保を避けるため固定長配列を維持した。
