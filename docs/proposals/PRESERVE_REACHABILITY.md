# 到達対象を変えずに、候補の壁を間引く

複数人が同じターンに設置しようとした壁をそのまま置くと、人の領域も分かれる場合がある。設置候補の一部を取りやめ、**全員をつなぎ直しつつ、誰かが到達できる対象を変えない**部分集合を探索する。解が複数なら共有領域の面積を最大化し、同面積なら保持する壁のビットマスクが小さい方を返す。

- [ヘッダー](../../library/preserve-reachability.hpp)
- [使用例](../../examples/preserve_reachability_usage.cpp)：2人を隔てる壁だけを外し、対象を隔離する壁を保持。
- [全列挙との比較](../../tests/preserve_reachability_test.cpp)：8,000個の乱択無向グラフ。独立した全頂点反復緩和を使って真値を求める。
- AHC008での適用箇所：少人数時の終盤で、実際に予定された複数の壁によって同じ空間にいた全員が分断されるとき。人を始点、動物がいるマスを対象とする。同じマスに複数頭いる場合、同じ到達性なので集合に畳める。そのターンの合法判定と設置命令の再構築は問題側で行う。

壁の解除は到達性を単調に増やす。全候補の壁を置いた状態で到達できた対象は、どの部分集合でも失われない。逆に、当初は届かなかった対象に到達した時点で、その壁をさらに外す枝を打ち切れる。この単調性は、**無向固定グラフ上で、固定した始点と対象に対して候補頂点を開く**場合に限る。始点は常に開いている必要がある。動物移動や時間の効果は判定しない。

候補が少数の局所修正向け。最悪は候補数を K として O(2^K(V+E))、APIの上限は20だが、AHC008での想定は6以下。大きな切断集合全体をこの全探索に置き換える用途には向かない。

```sh
g++ -std=gnu++23 -O2 -Wall -Wextra tests/preserve_reachability_test.cpp -o /tmp/preserve-reachability-test
/tmp/preserve-reachability-test
g++ -std=gnu++23 -O2 -Wall -Wextra examples/preserve_reachability_usage.cpp -o /tmp/preserve-reachability-example
/tmp/preserve-reachability-example
```

AHC008の同条件100件（人5〜6人・動物16頭以上、終盤の試行数を固定）では、旧専用コードとこの部品を組み込んだ版の全操作と公式得点が一致。分断を検出した48ターン中43ターンで部分集合を選んだ。速度向上は未確認で、既定解は変更していない。
