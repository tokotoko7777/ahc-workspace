# 行ビット集合でグリッドの成分だけを高速に求める

- 問題：AHC008。柵候補を置いた盤面で、人の連結成分の面積と動物の所属だけを繰り返し確認する。最短距離と経路は不要。
- 実装候補：`library/grid-row-flood.hpp`。盤面の通行可を行ごとの符号なし整数で渡す。列 c は下から c ビット目。上下左右の到達集合を、横方向の連続区間の一括伝播と行単位のキューで計算する。幅はワードのビット数以内。
- 使用例：`const auto area = ahc::row_flood<30,30>(open, 12, 7);`。面積は各行の `std::popcount` の和。到達不能な開始位置では全行が 0。経路や距離が必要なら既存 BFS を使う。
- 正しさ：独立した単純キュー BFS との 15,000 例、6 種類の盤面・ワード幅、全開／全閉／混在、パディングにも 1 があるケースを GNU C++23 の UBSan 付きで比較した。
- 30×30 の合成盤面、各密度 600 枚・30 周・3 反復の中央値。壁比率 5／25／45／70% で、単純キュー BFS 293.69／317.42／52.84／3.82 ms、行ビット版 12.51／28.64／10.64／3.52 ms。入力は既に行ビットで、行形式への変換は含まない。小さな成分や形式変換では速度差が小さくなり得る。
- 再現：`g++ -std=gnu++23 -O3 -fsanitize=undefined tests/grid_row_flood_test.cpp -o /tmp/row-flood-test && /tmp/row-flood-test`
