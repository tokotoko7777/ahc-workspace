# 改修提案：進行方向から見えない目的地を絞る

## 使う場面

グラフ上の相手が、観測できない目的地へ最短経路で動くとき、方向の履歴から候補目的地の分布を更新する。方向1回から目的地を決め打ちせず、分岐や目的地の再抽選を確率で残す。AHC008では猫の1歩目だけが目的地に依存する。実装時は局面更新から独立した小さな部品にする。

## 仕組みとAPI候補

- 観測前の位置を `x`、合法な隣接頂点を `y` とする。無向グラフなら `x` と各 `y` からのBFSだけで、全目的地 `v` について「`d(y,v)<d(x,v)`」を判定できる。目的地ごとのBFSは不要。
- 最短の方向へ一様に進むモデルなら、観測された方向が最短の場合は目的地の重みを最短方向数で割り、非最短なら0にする。正規化前の各方向の尤度の和が次方向の予測値になる。
- 目的地に着いた、または壁の追加で到達できなくなった重みを切り分け、問題側の再抽選分布へ移す。ランダムな2歩目を方向の観測として扱わず、到着による再抽選の判定には使う。
- 入力は現在の重み、距離配列、観測方向、到着条件。出力は方向分布、更新後の重み、再抽選に回る重み。BFS・ゲームの移動規則・行動への変換は呼び出し側に置く。

## 検証と保留

AHC008配布100件の人側に残る猫50,358ターンでは、次の1歩目を最も高確率とした方向の的中率（同率は按分）が、一様な合法方向31.3%、毎ターン一様に目的地を選ぶ37.1%、観測履歴を使う69.7%。別の公式生成100件・51,398ターンでも31.4%、36.8%、70.3%。合法方向一様と履歴方式のBrier値はそれぞれ配布0.687→0.361、別生成0.686→0.356（小さいほどよい）。どちらも基準解の再生上の予測であり、捕獲率や得点ではない。

汎用ヘッダー化前に、小グラフの全目的地を列挙する愚直計算と照合する。直線・分岐・同率最短・遮断・到着・観測できない方向をテストする。AHC008では次に、配置を変える前に「担当の到着ターンに3〜4マス区画の合法位置へ入る」予測も改善するかを測る。採用版への組み込みは未実施。
