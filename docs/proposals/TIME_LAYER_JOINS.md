# 時刻付き経路の往路・復路を一度に計算する

[ヘッダ](../../library/time-layer-joins.hpp)・[小さな使用例](../../examples/time_layer_joins_usage.cpp)・[全列挙との照合](../../tests/test_time_layer_joins.cpp)

時刻によって通れる辺や行動の費用が変わるとき、出発から中間時刻の各頂点へ着く最小費用と、そこから期限の指定点へ戻る最小費用を求める。中間時刻での所属頂点を指定して `via(v)` で合計を取り、通れない場合は `infinity` が返る。待つ行動は利用側が自己辺として列挙する。任意の有向グラフを使え、既定経路との違いを 0/1、移動を重み付き費用にするなど、費用指定は呼び出し側に任せる。

中間時刻まで前向きに最小値を渡し、終了側から同じ辺を逆向きに読み進める。頂点数 V、1層の辺数 E、時間幅 T のとき O(T(V+E))・補助領域 O(V)。辺の費用は非負で、通れない辺は `TimeLayerJoin::infinity`。上限を超える合計は同値に切り詰める。途中状態の最小費用だけを返すため、実際の経路や担当割当の復元は別。呼び出し側で頂点添字を範囲内に保つ。

AHC008では未完了になった21件の予約を再検証。前後の実際の柵設置・横移動を固定し、予定する捕獲のターンに入口で待ち、次の既定位置までに戻れるか調べた。入口を閉めた後は復路で通行不可。9件に候補時間があり、7件で元作業へ戻れる。そのうち6件は元から捕獲できていた。問題固有の合法性、共有地500マス、実際の動物移動は別検証であり、ヘッダはそれらを仮定しない。

合成の有向グラフ4,200件・16,664中間頂点で総当たりと一致（ASan/UBSanでも照合）。実盤面では9場面・18担当の900頂点の前向き・後ろ向きの費用を、独立のPython実装と全件突き合わせた。

```sh
g++ -std=gnu++23 -I library tests/test_time_layer_joins.cpp -o /tmp/time-layer-test && /tmp/time-layer-test
g++ -std=gnu++23 -I library examples/time_layer_joins_usage.cpp -o /tmp/time-layer-example && /tmp/time-layer-example
```
