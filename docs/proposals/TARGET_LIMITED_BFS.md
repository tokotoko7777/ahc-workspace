# 目的地と距離上限だけを求めるBFS

[ヘッダ](../../library/target-limited-bfs.hpp) /
[最小例](../../examples/target_limited_bfs.cpp) /
[検証](../../tests/target_limited_bfs_test.cpp)

全頂点の距離は不要で、たとえば「候補の動物・作業点に30歩以内で届くか」
しか見ないときに使う。幅優先順のまま、距離上限を超えた層の手前か、
要求した到達点をすべて見つけた時点で打ち切る。要求した頂点について
普通のBFSと同じ距離を返す。**要求外の距離は未完成なので使わない。**
到達不能・上限超過は `inf` のまま。例えば30歩を上限にするなら、
`inf > 30` の表現可能な整数にする。

既存壁に追加するだけなら、元の連結成分が異なる目的地は事前に
除いてよい。壁を取り除いて接続が増える場合は、この除外は使えない。
隣接の負値は番兵として無視。非負の番号は配列の範囲内とする。
始点は常に距離0で入れ、`open` は移動先に適用。与える辺は単位距離。

## 検証

- 有向グラフを含む1万例で、全探索BFS・距離打ち切りと一致。
  `g++ -std=gnu++23 -Wall -Wextra -Werror tests/target_limited_bfs_test.cpp -o test && ./test`
- AHC008の空き担当を割り当てる距離に適用。元の盤面の連結成分が
  異なる動物を除き、通路から30歩以内だけを局所計算する。
  構築・担当選択・最短路の同順位は変えない。
- 30×30の4,200条件では、同じ動物への距離結果を確認しつつ、
  BFSが展開したセルは2,148,677から1,480,814に減った。
  これは探索の展開数であり、そのまま実行時間ではない。
- 汎用ヘッダ組込み版のC++23単一ファイルは、公式配布100件・
  同じ探索24波で全操作、採点、探索内集計が手書き版と一致。
  先に採用した手書き版については、同じ2,400ms内の探索波が
  配布100件で1,438→1,512、別生成100件で1,831→1,960。
  両比較とも全操作・得点が不変。ヘッダ組込み版の同時間性能は別計測。
