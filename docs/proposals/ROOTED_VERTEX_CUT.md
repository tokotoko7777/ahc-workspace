# 柵を置いた後に、人側に残る領域をまとめて調べる

[ヘッダ](../../library/rooted-vertex-cut.hpp)・[短い使用例](../../examples/rooted_vertex_cut_usage.cpp)・[愚直BFSとの比較](../../tests/test_rooted_vertex_cut.cpp)

無向グラフの一つの始点を維持したまま、各頂点を通れなくしたときの始点側領域の大きさを求める。人や対象など最大64個の区別したラベルを載せて、どれが始点側に残るかも同時に返せる。ラベルは頂点が重なっても使えるが、1つのラベルを複数の頂点に置くことはできない。

始点から深さ優先探索し、子部分木ごとに最も早く戻れる訪問番号と、部分木の大きさ・ラベルの和を記録する。頂点を消したときに親側へ迂回できない子部分木と、その頂点自身を除く。固定領域の構築は O(V+E)、候補1個の照会は O(1)。2頂点なら、最初の候補だけ閉じて1回構築すれば、続く候補をまとめて読める。始点を消す照会や無効頂点は `nullopt`。始点の連結成分外を消した場合は変化しない。二重辺のない無向グラフ、添字で参照できる隣接リストを想定する。

AHC008では、終盤の実盤面で未マークの柵1・2枚を置く場合に、人と動物をそれぞれ別のラベルに割り当てて使用。人が全員一つの陣地に残るか、対象を隔離できるか、陣地が500マス以上かを高速に分けて調べた。柵の合法性や担当の割当、隔離区画4マス以下かどうかは別に確認する。診断区間102場面の合法候補について、問題内の直接実装と本ヘッダの領域・ラベルが一致した。

ランダムな格子700件で、単独削除33,600件、2頂点削除616,424件を愚直BFSと突き合わせた。研究用部品で、これだけで得点や実行時間が改善するという意味ではない。

```sh
g++ -std=gnu++23 -O2 -I. tests/test_rooted_vertex_cut.cpp -o /tmp/rooted-cut && /tmp/rooted-cut
g++ -std=gnu++23 -O2 -I. examples/rooted_vertex_cut_usage.cpp -o /tmp/rooted-cut-example && /tmp/rooted-cut-example
```
