# AHC069

[公式問題](https://atcoder.jp/contests/ahc069/tasks/ahc069_a) /
[公式 Rust テスター・ジェネレータ](https://img.atcoder.jp/ahc069/AdcJXWH4.zip)。
50×50 の公園で到着順にグループを受け入れ、退園時まで連結な芝生を
割り当てます。既知の退園時刻以外に、まだ到着していない情報は使いません。

## コンパクトな空き地と、一組の再配置

全行・全列の利用中または池の位置を 50-bit のマスクにします。
基準は長方形の端の一列だけを短くした連結形状を縦横に試し、
境界長が最短で、壁や利用中の領域に接する辺が多い場所を選びます。
場所がなければ入園を断り、既存グループは移動しません。

候補は直接置けない場合だけ、移動費が面積に比べ小さい最大 4 組を
一組ずつ一時的に外します。新着を先に置いてから移動先を探し、
移動費とこれまでで最も悪いコンパクトさによる使用料の差を含めて、
新着の使用料が上回る提案だけを確定します。
両方式の通常配置は同じで、再配置版には追加探索があります。

| 独立シード | 移動なしの絶対点 | 一組再配置あり | 受入数（なし → あり） | 勝・負 |
|---|---:|---:|---:|---:|
| 開発 14 件 | 723,227,788 | 746,752,893 | 9,432 → 9,510 | 11・3 |
| 凍結後・未調整 28 件 | 1,349,350,404 | 1,388,914,694 | 17,748 → 17,959 | 22・6 |

未調整では絶対点 +2.93%、移動 591 回。再配置を既定に採用し、
`-DAHC069_NO_MOVES` で移動なし対照を再現できます。
全 84 対戦は連結性・同時移動・退園・費用を独立に検証し、
公式 `tester` と C++ の絶対点も一致。CPU 7 固定で最大 0.229 秒未満。
C++23 の単一ファイル版は 57,334,370 点で、通常版と全出力一致です。
独立リプレイのテストは、二組が同時に場所を交換できること、
移動後も最悪のコンパクトさを保持することを検査します。

汎用 `axis-aligned-rectangle.hpp` だけでは現在の多数の空き形状や
末尾が一部だけの行を効率的に調べられず、占有マスクの積と行幅の
走査を問題側に実装しました。利用部品は今回増やしていません。
次は一組の移動で直接埋める方法と、後から高収益の客を受けられるよう
既知の退園時刻で将来の空き容量を計算して受け入れを見送る方法を比べます。

## 本番比較

絶対点は全退園後の `max(売上−移動費,0)`。本番 2,000 ケースにつき
`round(10^9 YOUR / MAX)` を足します。2 秒・1,024 MiB、
不正・時間超過のケースは 0 点で MAX から除外されます。
