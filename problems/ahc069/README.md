# AHC069

[公式問題](https://atcoder.jp/contests/ahc069/tasks/ahc069_a) /
[公式 Rust テスター・ジェネレータ](https://img.atcoder.jp/ahc069/AdcJXWH4.zip)。
50×50 の公園で到着順にグループを受け入れ、退園時まで連結な芝生を
割り当てます。既知の退園時刻以外に、まだ到着していない情報は使いません。

## コンパクトな空き地と、一組の再配置

全行・全列の利用中または池の位置を 50-bit のマスクにします。
基準は長方形の端の一列だけを短くした連結形状を縦横に試し、
境界長が最短で、壁や利用中の領域に接する辺が多い場所を選びます。
場所がなければ入園を断り、既存グループは移動しません。

候補は直接置けない場合だけ、移動費が面積に比べ小さい最大 4 組を
一組ずつ一時的に外します。新着を先に置いてから移動先を探し、
移動費とこれまでで最も悪いコンパクトさによる使用料の差を含めて、
新着の使用料が上回る提案だけを確定します。
両方式の通常配置は同じで、再配置版には追加探索があります。

| 独立シード | 移動なしの絶対点 | 一組再配置あり | 受入数（なし → あり） | 勝・負 |
|---|---:|---:|---:|---:|
| 開発 14 件 | 723,227,788 | 746,752,893 | 9,432 → 9,510 | 11・3 |
| 凍結後・未調整 28 件 | 1,349,350,404 | 1,388,914,694 | 17,748 → 17,959 | 22・6 |

未調整では絶対点 +2.93%、移動 591 回。初回の一組再配置は `-DAHC069_NO_RESERVE`、
`-DAHC069_NO_MOVES` で移動なし対照を再現できます。
全 84 対戦は連結性・同時移動・退園・費用を独立に検証し、
公式 `tester` と C++ の絶対点も一致。CPU 7 固定で最大 0.229 秒未満。
C++23 の単一ファイル版は 57,334,370 点で、通常版と全出力一致です。
独立リプレイのテストは、二組が同時に場所を交換できること、
移動後も最悪のコンパクトさを保持することを検査します。

汎用 `axis-aligned-rectangle.hpp` だけでは現在の多数の空き形状や
末尾が一部だけの行を効率的に調べられず、占有マスクの積と行幅の
走査を問題側に実装しました。利用部品は今回増やしていません。

## 本番比較

絶対点は全退園後の `max(売上−移動費,0)`。本番 2,000 ケースにつき
`round(10^9 YOUR / MAX)` を足します。2 秒・1,024 MiB、
不正・時間超過のケースは 0 点で MAX から除外されます。

## 追加実験: 受入の機会費用と退園予測

現在知られている客だけを用い、直近までの平均面積・滞在時間・
価値密度と、現在までの到着時刻・件数から、候補客の滞在中の
占有圧力を 6 点で近似します。価値÷面積時間が予測した機会費用を
下回れば、置けても受入を見送ります。配置と一組再配置は両方式共通です。
対照は現時点の占有を 6 点に据え置き、候補は既知の退園を各切片に反映。
同じ予測条件・形状探索上限ですが、見送り件数によって実行量は違います。

| 独立シード | 受入選別なし | 現在占有のまま | 退園を反映 | 退園反映の勝・負（対現在占有） |
|---|---:|---:|---:|---:|
| 開発 14 件 | 646,033,483 | 663,248,371 | 674,274,672 | 9・5 |
| 凍結後・未調整 28 件 | 1,430,559,731 | 1,557,336,616 | 1,521,666,493 | 8・20 |
| 追加・未調整 24 件 | 1,273,439,860 | 1,335,099,488 | 未実施 | — |

退園を反映する案は未調整で据え置きより 2.29% 低下し不採用。
予定の退園は空き面積を増やしても、それが新着用に連結で空くことを
保証しないため、面積のみの予測では緩くなりすぎる可能性があります。
一方、現在占有のまま価値選別する案は、初回より未調整で +8.86%
（25 勝・3 負）、追加未調整でも +4.84%（17 勝・6 負・1 同）。
こちらを既定に採用します。全 216 実行は同じ絶対点で、
CPU 7 固定の最大は 0.346 秒未満。単一ファイルでも 20,476,527 点と
全対戦出力が同じでした。`-DAHC069_RESERVE_RELEASES` は不採用案、
`-DAHC069_NO_RESERVE` は初回版です。全ケースは公式と独立で照合しました。

```bash
bash problems/ahc069/run_reserve.sh build/ahc069-reserve "$gen" "$tester" 7
```

## 本番 2,000 件の凍結監査

現在占有で受入選別する C++23 単一ファイルを
`27189baae07e355a6c84ce28ae928484ceb05572` で凍結しました。
公式 ZIP の未変更ジェネレータに本番種を渡した入力と、
同じ ZIP の別コピーでメタデータだけを stderr に記録して生成した
入力を全件バイト比較しました。公開の順序、`R`、池の生成数二種が
2,000 件とも一致し、履歴の公式 1 位を再現してから実行しました。

公式テスターの料金・費用は整数境界で厳密に丸めるため、
独立検証も `isqrt` による使用料と千分率による移動費の
整数式で計算しました。凍結した C++ の stderr は浮動小数点の
参考表示です。桁境界に出る表示差は別に記録し、採点や
解法修正には使いません。公式と独立検証の点数は一致が必須です。
[丸めの回帰テスト](../../tests/test_ahc069_replay.py)もあります。

```bash
bash problems/ahc069/run_official_audit.sh build/ahc069-official \
    "$official_zip" "$seeds" "$input_csv" "$result_csv" 7
```

比較するケース別最大値は双方に共通で、履歴 1,128 人で固定、
または凍結版を仮追加した集団で再計算の二方式です。
公式への再提出ではなく、本番ケースを同じ公式条件で測った
ローカルの結果です。ケースごとの結果は手法の調整に使っていません。

| ケース最大の共通条件 | 公式 1 位 asi1024 | 凍結版 | 比較 |
|---|---:|---:|---|
| 履歴 1,128 人で固定 | 1,981,252,894,878 | 1,336,637,386,355 | 612 位相当、同点なし |
| 凍結版を仮追加した 1,129 人で再計算 | 1,981,252,894,878 | 1,336,637,386,355 | 612 位相当、同点なし |

全 2,000 件が合法で公式と独立検証が一致し、ケース最大値の更新なし。
絶対点の合計 111,443,279,822、全体で受入 1,223,631 件・移動 34,040 件。
CPU 7 固定のテスター込み最大壁時間 0.451 秒未満。
C++ の参考表示差は 5 件、絶対値の最大は 1 でした。
1 位には 644,615,508,523 点届かず **未達** です。
凍結した単一ファイルの SHA-256:
`3bce00c01c16967e0c1123e8fea7ace89fec428e16248c49d000142282f8fdc2`。
