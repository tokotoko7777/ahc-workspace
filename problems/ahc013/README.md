# AHC013

[公式問題・採点規則](https://atcoder.jp/contests/ahc013/tasks/ahc013_a) /
[公式 Rust ツール](https://img.atcoder.jp/ahc013/a42302b3af.zip)。
計算機の移動後、交差しない直線配線を作ります。移動数と接続数を
足して `100K` 以内です。

## Ａ/Ｂ

基準版は移動せず、各計算機から右・下に見える最初の計算機が同種なら
配線候補を作ります。短い配線や大きな同種連結成分の候補を優先する
32 通りの順番を試し、交差しない同種クラスタの得点が最大の解を採ります。

移動版はこの基準解を保持した上で、空席への隣接移動を仮適用し、
競合しない配線を引き直して比較します。配線の得点を見て局所的に
移動を選び、最良経路の途中からの再始動も試します。移動で残りの
配線枠が減る点を採点に反映し、探索時間は固定回数と 0.9 秒の両方で
打ち切ります。乱数種は内部固定です。単純比較は追加時間での改善であり、
同時間枠での優位までは示していません。

| 独立生成の共通入力 | 移動なし | 移動あり | 差 | 移動あり勝ち |
|---|---:|---:|---:|---:|
| 開発 12 件（各 K 3 件） | 7,294 | 37,991 | +30,697 | 12/12 |
| 凍結後・未調整 20 件（各 K 5 件） | 11,377 | 64,679 | +53,302 | 20/20 |

全 64 実行で移動・配線を独立再生し、公式 `vis` と得点が一致。
Linux CPU 7 固定の最大壁時間は移動版 0.841 秒未満です。
移動版を作業ブランチ既定にし、本番順位は未判定とします。

## 本番条件

同一クラスタ内の同種ペアで +1、異種ペアで −1、別クラスタで 0。
各ケースは合計を負なら 0 に切り上げ、最終 2,000 件（100 種の `N,K`
に対し各 20 件）の合計を最大化します。1 ケースの制限時間は 3 秒、
メモリ上限 1,024 MiB。システムテストで非 AC はその 1 件だけ 0 点です。

[公式本番シード](https://img.atcoder.jp/ahc013/seeds.txt) は 2,000 件で、
SHA-256 `0a50dccf4689292f69a36be0ea1a99767de055434b854f2b0bc7f1fd40f9033e`
を照合済み。今回の A/B はこれらと重複しない生成シードだけを使いました。
[公式最終順位表](https://atcoder.jp/contests/ahc013/standings) は未ログインだと
得点を表示せず、[公式結果ページ](https://atcoder.jp/contests/ahc013/results)
には得点欄がありません。最終 1 位の成績は未取得で、本番入力の生成・
評価・AtCoder への提出もしていません。公式順位表の得点が参照でき、
本番と同じ 2,000 ケースを検証したときだけ厳密に比較します。

## 再現・ライブラリ

公式配布 zip SHA-256:
`f237a241d71e4130824b52a3490c83bb405dd78d9f9723647872b238e04f24bb`。
ツールを `cargo build --release --locked --bin gen --bin vis` でビルドし、
得られた `gen` と `vis` の絶対パスを指定します。

```bash
bash problems/ahc013/run.sh build/ahc013 "$gen" "$vis" 7
```

C++23 提出用の単一ファイルも生成・ビルドします。未調整ケース 1 件で
単一ファイルの出力を再検査し、通常ビルドと同じ 5,143 点でした。
移動版の凍結バイナリ SHA-256:
`c8b9ec743508c43fbf2135173cdde81f3aaebe1ee7086adbe48783197541eff8`。

移動を試すたびに 4 方向の最初の占有セルが必要です。グリッド BFS は
この用途に合わないため、行・列ごとのビット集合を更新する
[`GridLineOccupancy64`](../../library/grid-line-occupancy64.hpp) を追加しました。
[使用例](../../examples/grid_line_occupancy64_usage.cpp)、
[愚直走査との比較テスト](../../tests/grid_line_occupancy64_test.cpp)、
[API](../../docs/LIBRARY_REFERENCE.md#gridlineoccupancy64)。

次は、配線端点同士を一度の移動で並べられないときに、同種の大きな
クラスタをつなぐ 2〜数手の移動を候補にします。特に未調整集合では
K=5 の平均が 1,587.2 点に留まったため、距離が近くても別種の計算機が
妨げている区間を優先し、同時間で単発移動を増やす版と比較します。
