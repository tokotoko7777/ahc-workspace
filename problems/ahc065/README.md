# AHC065

[公式問題](https://atcoder.jp/contests/ahc065/tasks/ahc065_a) /
[公式 Rust ビジュアライザ・ジェネレータ](https://img.atcoder.jp/ahc065/b8iUCXAV.zip)。
倉庫へ設置したコンベアを回転させ、番号の順に箱を搬出します。

## 等距離の搬出経路から、後続箱も運ぶ経路を選ぶ

隣接する二行の周囲に長方形ループを作り、二列でも同じ設置をします。
各セルが含まれるループはちょうど二本。隣接する水平・垂直辺が
少なくともどちらかに含まれるので、どの箱も出口までマンハッタン
距離を毎手 1 ずつ減らせます。箱ごとの距離は最大 29 のため、
同じ操作で後続箱が動いても全 400 箱を高々 11,600 手で搬出できます。

固定した設置上で、いま搬出する箱の最短経路を両方式とも 8 本抽出。
全箱の同時回転と次の搬出番号をシミュレートします。
対照は搬出直後の次の箱の距離で選び、候補は次の 8 箱の距離の
重み付き和で選びます。現在箱の手数はどの候補も同じです。
後続の同じ箱に同じ数の候補を試しますが、選択後の盤面と総手数は異なります。

| 独立シード | 次の一箱の得点 | 次の八箱の得点 | 手数（一箱 → 八箱） | 八箱の勝ち |
|---|---:|---:|---:|---:|
| 開発 14 件 | 72,396,675 | 74,665,823 | 77,722 → 69,470 | 14/14 |
| 凍結後・未調整 28 件 | 144,695,725 | 149,371,055 | 155,828 → 138,801 | 28/28 |

未調整で手数 10.93% 減、公式得点 3.23% 増。次の八箱を既定、
`-DAHC065_ONE_FUTURE` で一箱版を再現します。
全 84 実行で設置制約、回転方向、搬出順と全箱搬出を独立検証し、
公式 `vis`・独立再生・C++ 手数が全件一致。
CPU 7 固定で最大 0.046 秒未満。
単一ファイル C++23 版は 5,323,660 点で通常版と出力一致です。

通常の連続区間の rotate では、離れた盤面添字の入れ替えと
各箱の逆引き更新をまとめにくかったため、
[scattered-cycle-rotation](../../library/scattered-cycle-rotation.hpp)
を追加しました。[短い例](../../docs/LIBRARY_REFERENCE.md#scattered-cycle-rotation)と
[12,000 回のコピー再計算テスト](../../tests/scattered_cycle_rotation_test.cpp)
で、盤面と逆引きが同時に合うことを確認しています。
次は、現在だけでなく次の箱の搬出も実際に再生する二箱先の探索を、
同じ回転試行予算で比較します。

## 本番比較

全 400 箱の搬出は `10^6 + round(10^6 log2(10^5/T))` 点、
未完は `round(10^6 B/N²)` 点、最大化します。
2 秒・1,024 MiB、本番 150 ケースの和、終了後のシステムテストなし。
一つでも不正・時間超過があれば提出全体が 0 点です。
[公式結果](https://atcoder.jp/contests/ahc065/results/json)の 1 位は
rabot。点数は掲載されておらず、
[得点 CSV](https://img.atcoder.jp/ahc_standings/ahc065/result.csv)・
[入力対応表](https://img.atcoder.jp/ahc_standings/ahc065/input.csv)は HTTP 403。
公式ツール同梱の 100 種が本番 150 ケースの代用になる根拠もないため
**未判定** です。本番入力や他人の解法・提出コードは使っていません。
