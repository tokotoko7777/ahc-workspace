# AHC027

[公式問題・採点規則](https://atcoder.jp/contests/ahc027/tasks/ahc027_a) /
[公式 Rust ジェネレータ・ビジュアライザ](https://img.atcoder.jp/ahc027/aPdjCUIZ_v2.zip)。
壁を通らず全マスを訪れ、原点に戻る巡回を作ります。長さは 100,000 手以内です。

## Ａ/Ｂ

基準版は、移動できる隣接マスの探索順を変えた DFS の木を作り、
行き帰りの巡回を比較します。局所変更版は同じ初期 48 本から始め、
元の区間を合法な 1 辺で短絡、両端を合法につなぎ直せる区間の反転、
隣接マスへ往復する 2 手の挿入を試します。全マスを訪れなくなる
候補は捨て、反復中に得た最良のルートを残します。双方の探索時間枠を
440 ms とし、候補の回数にも上限を置きました。

巡回中のあるマスの訪問間隔が `g` なら、間に増える汚れの合計は
重みを除いて `g(g−1)/2` です。周期をまたぐ間隔も同様に足し、
周期長で割った平均を比較します。比例比較は整数の積を使います。

| 同じ新規入力 | DFS の絶対点合計 | 局所変更版 | 局所変更版勝ち |
|---|---:|---:|---:|
| 開発 12 件 | 373,539,272 | 305,718,347 | 11/12 |
| 凍結後・未調整 24 件 | 623,349,268 | 568,819,988 | 19/24 |

絶対点は小さい方が良く、確認集合では 8.75% 減少しました。
確認集合の巡回長合計は 46,218→39,738 手です。
全 72 実行で壁・隣接・全セル訪問と原点への帰還を独立検査し、
2 周の汚れの直接再生が公式 `vis` の整数点と一致しました。
CPU 7 固定の最大壁時間は DFS 0.456 秒未満、局所変更版 0.445 秒未満。
初回の作業ブランチ既定は局所変更版で、凍結 SHA-256 は
`855ec99fa93f172f8e841431608bad16eca554709efdd3801aadade648891c5f`。

## 本番順位との比較

2 周目の平均汚れを四捨五入した絶対点を最小化します。本番順位点は
各ケースの `round(10^9 × 参加者最小の絶対点 / 自分の絶対点)` を
2,000 件で合計して最大化します。非 AC のケースは順位点 0 かつ
最小値の算出から除外されます。制限時間 2 秒、メモリ 1,024 MiB。

本番最終 1 位は **1,996,375,186,737 点**。
[AtCoder 提供 ALE-Bench アーカイブ](https://huggingface.co/datasets/SakanaAI/ALE-Bench/blob/main/ahc027.zip)
の SHA-256 `f557d24377e00d105d6d2a0c5c5413166b6fe87662bdea5b4f163e0b64f21e1b`
を照合し、順位・得点の CSV のみを確認しました。
[公式公開シード](https://img.atcoder.jp/ahc027/seeds.txt) 2,000 件は
SHA-256 `cdea33a6050850bf1387e2191b802a1df7e43fcb969fd6c3bf9cbd96a4d790d7`
と一致し、開発・確認のシードはこれと重複しません。ケース別の
本番最小絶対点は未取得で、本番入力は生成・評価していません。
**厳密な本番順位は未判定**です。

## 再現とライブラリ

公式 zip の SHA-256:
`cb237468c91f8b4e7f27ffc5df26d8c4e9ffbeeee3d9d48b8cd91c2190fe63b2`。
ツールを `cargo build --release --locked --bin gen --bin vis` でビルドし、
`gen` と `vis` の絶対パスを指定します。

```bash
bash problems/ahc027/run.sh build/ahc027 "$gen" "$vis" 7
```

C++23 提出用の単一ファイルを生成・ビルドし、未調整の 1 件で
通常ビルドと同じ 1,390,633 点を確認しました。
周期をまたぐ重み付き訪問間隔を集計する既存部品がないため、
[`CyclicVisitEnergy`](../../library/cyclic-visit-energy.hpp) を追加しました。
[小さな使用例](../../examples/cyclic_visit_energy_usage.cpp)、
[1,200 件の直接シミュレーション比較](../../tests/cyclic_visit_energy_test.cpp)、
[API](../../docs/LIBRARY_REFERENCE.md#cyclicvisitenergy)。
既存提出や外部解説は使っていません。

次はランダムな往復だけでなく、`汚れやすさ × 訪問間隔²` が大きい区間を
選んで、時間的な中点の近くからそのマスまで短い寄り道を入れます。
道を長くする副作用を同じ厳密な汚れの評価で測り、同時間の局所変更版と
新規シードで比較します。

## 長い訪問間隔の中を埋める追加実験（採用）

初回の局所変更版のあとに最大 150 ms を追加しました。同時間の対照は
ランダムな短絡・区間反転・2 手往復を足す版です。
新しい版では `汚れやすさ×訪問間隔²` が大きい上位 180 区間から選び、
時間上の中点近くにいるマスから、7 辺以内の開いた道があれば往復を
入れます。同じ予算の一部は対照と同じランダムな変更に使い、
どちらも実際の周期汚れが下がる変更だけを採ります。

| 新規の共通入力 | 初回版 | 同時間のランダム追加 | 中点狙い | 中点狙いが対照に勝ち |
|---|---:|---:|---:|---:|
| 開発 10 件 | 217,862,419 | 153,668,239 | 145,005,258 | 7/10 |
| 凍結後・未調整 20 件 | 368,444,085 | 286,174,236 | 275,950,662 | 16/20 |

未調整集合では対照比 3.57% 減、初回版には 20/20 件で勝ちました。
巡回長合計は対照より長い一方、汚れやすいマスの長い待ち時間を
減らして平均汚れを下げています。全 90 実行で合法、公式 `vis` と
2 周の独立再生が一致。CPU 7 固定の最大壁時間は中点狙い 0.596 秒未満、
対照 0.600 秒未満。C++23 提出用単一ファイルもスモーク確認しました。

```bash
bash problems/ahc027/run_gaps.sh build/ahc027-gaps "$gen" "$vis" 7
```

中点狙い版を作業ブランチの既定にし、初回版は
`-DAHC027_FIRST_SPLICES` でビルドできます。この追加実験にも
本番ケースは使っていません。本番順位は未判定のままです。
次は寄り道から元の出発点へ戻らず、少し先の巡回に合流する置き換えを
試します。省く区間に最後の訪問しかないセルがないかも厳密に確認し、
同時間でルート延長の副作用を減らせるか比較します。
