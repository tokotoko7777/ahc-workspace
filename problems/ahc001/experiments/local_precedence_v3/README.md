# AHC001: 同じ終盤配置での局所的な軸順序修復

前回の強制軸変更は154回の合法途中配置を得ても、12枚以上を壊した
地域全体の再構築で採用が0回でした。今回は v64 を同一ケース・4.8秒で
一度だけ実行し、3群すべてにまったく同じ出力を渡します。v64本体は変更しません。

- **修復なし**: v64 配置そのもの。
- **同じ軸**: 元の分離軸を保持しながら、ペアの面積・位置を再調整。
- **直交軸**: 元の軸に正の重なりを作り、反対軸でのみ分離させる。

2つの修復群は同じ候補ペア最大12組、ペア当たり2つの余白、2つの共通
座標、3つの切り方を検査します。各候補は常に開始時点の配置から再開。
変更候補と直接接触しうる隣接長方形だけ最大3枚を対象にし、対象のペアを
固定したうえで、隣接長方形を元の形の部分区間にクリップします。
実際には衝突しない隣接長方形は変えません。他の長方形は完全固定です。
各軸の収まり、指定点、非重複を独立に検査し、公式得点を照合します。
元より改善しない場合は元配置を出力します。

公開本番のシード一覧は重複確認にだけ使います。開発6件と未調整確認6件は
異なる SHA-256 接頭辞から生成しました。本番ケース別データや得点を調整に
使用しておらず、後処理だけの実測を v64 の 4.8 秒に足して提出できるとは
仮定しません。

## 再現

公式の gen/vis を Rust release ビルドし、`GEN`, `VIS`, `OFFICIAL_SEEDS`
に設定します。`V64` は既存の凍結 C++23 v64 バイナリです。

```sh
p=problems/ahc001
r=$p/experiments/local_precedence_v3
d=$(mktemp -d)
g++ -std=c++23 -O3 "$r/local_repair.cpp" -o "$d/repair"
python "$r/benchmark.py" "$GEN" "$VIS" "$V64" "$d/repair" "$OFFICIAL_SEEDS" "$d/run"
```

## 結果

| 条件 | 修復なし平均 ↑ | 同じ軸平均 ↑ | 直交軸平均 ↑ |
|---|---:|---:|---:|
| 開発6件 | 992,070,899.67 | 992,070,899.67 | 992,070,899.67 |
| 未調整6件 | 991,034,021.33 | 991,034,021.33 | 991,034,021.33 |

両修復群とも試行数は各1,728、合法な中間配置は同じ軸937件・
直交軸538件。最終得点が元配置を超えた中間配置は両群とも **0** で、
全36出力は合法、独立検査と公式採点が一致しました。後処理の最大実測は
0.007396秒でした。これらのローカル近傍は **v64に組み込みません**。
[取得結果](results.csv)。

次に当たりを付けるなら、すでに最終配置で接しているペアを整えるのでなく、
複数の希少な長方形が同じ空き領域へ伸びようとする競合を評価し、
初期～中盤の配置の段階で分離軸を選ぶ。異なる初期トポロジーからの
同予算の最終焼きなましを複数比較し、点数差を後処理の成否と混同しない。
