## 代表点削除の差分化

削除時に以前の2経路と新しい1経路だけを差し引き、変化した区間に接する道路だけを再確認する。最短経路に同コストの候補が複数あると、逆向きは異なる経路を取り得るため、有向の訪問区間を個別に保持。合成10マップの2,219削除候補で全経路を展開した照合と一致。固定作業では採用順序と移動文字列が一致し、削除処理は4〜9倍。

公式配布100件では [22,911,304点](speed-cover-results.csv)、基準比−11,953点（31勝41分28敗）、全件合法・完全可視・両採点一致。最大2.620920秒（基準2.709380秒）、中央値2.609492秒（基準2.638273秒）、SA総試行数477,892,608（基準445,565,440）。時計で探索を切るため公式点の小差や試行数を差分処理だけに帰属しない。得点最良の基準版は維持する。[単一ファイル](speed-cover.single.cpp)は `g++ -std=c++23` のみでビルドした。

## 橋を通る回数の診断

基準版の経路を変更せず、道路グラフの橋を調べた。橋を起点から遠い側に渡った先に、橋と同じ直線区間だけでは見えないマスがあると、その橋を通る必要がある。100件で必須と判定した1,458本はすべて往復一度だけ。任意の28,205本は一度も渡っておらず、橋の通過を減らせる移動コストは0だった。成分の内部経路には別途改善の余地がある。

```sh
python3 problems/ahc005/experiments/official100/bridge-audit.py BENCHMARK_ASSETS
```

`BENCHMARK_ASSETS` には公式入力 `in/` と測定済みの `baseline100/baseline/` を置く。探索・採点の再実行は不要。

## 最短路前計算のバケット化

正の小さな進入費用に対して、優先度付きキューを10個の循環バケットに置換。同距離の前駆は旧版と同じIDを選び、旧版と全端点距離・前駆・初期経路が合成60マップで完全一致。固定作業ではN=25〜65の前計算が4.7〜5.6倍。ただし探索を含む全体がその倍率になるわけではない。

公式100件では [22,878,088点](bucket-paths-results.csv)、基準比−45,169点（27勝41分32敗）。完全可視・合法・両採点一致100件、最大2.705513秒。SA総試行は487,816,192（+9.48%）、ケース中央値4,844,800（基準4,448,000）。試行数は増えたが最終得点は伸びず、今回の最高得点版には採用しない。[単一ファイル](bucket-paths.single.cpp)は `g++ -std=c++23` のみでビルドした。

## 基準の再計測と異なる初期経路からの2スタート

基準と同じ実行ファイルの再計測は [22,922,620点](baseline-repeat-results.csv)。基準初回との差は−637点。両採点が一致、最大2.712813秒。

[2スタート版](multistart.single.cpp)は元の2.60秒の探索終了時刻を変えず、探索に残った時間を58%と42%に分ける。第1は従来の初期経路、第2は近い候補群の選択にゆらぎを加えた別初期経路と乱数を使用。両方の経路を展開・検査して、合法で最も移動費用が小さい経路だけを出力する。

公式配布100件で [**23,020,218点**](multistart-results.csv)、基準比+96,961点（45勝39分16敗）。全件合法・完全可視・両採点一致、最大2.812822秒。両スタート合計の探索試行数466,727,936、ケース中央値4,645,248。
単一ソース SHA-256: `8eeed40a574bf5c39af92aeed6b5623921d4d09e9661a23ec8d275cfabaa6939`。

## 順序をまとめて変える近傍と、短い区間の診断

- まれに4辺を切り、3区間を向きを保ったまま入れ替える版は [22,951,190点](double-bridge-results.csv)。基準比+27,933点だが2スタート版より低い。全件合法・完全可視・両採点一致、最大2.705633秒。2万比較で4辺差分と有向の全移動費用が一致。[単一ファイル](double-bridge.single.cpp)。
- 固定順序の代表点を厳密に選び直すDPは、合成4件で焼きなまし直後の費用と同じ。連続2〜4群を並べ替え、代表点も同時に選ぶ仕上げでは合成4件の11,016候補で改善0。どちらも公式100件の採点には進めない。
- 未カバーの視界を狙う迂回の置換は、合成6件の10,621短縮候補で完全可視を保つ改善0。合成試験での不採用で、一般的な不可能性を示すものではない。

## 13:00切替時点の結論と未使用100件

公式配布100件の最良は2スタート版の **23,020,218点**（目標より+701,448点）。コードは研究枝に保存し、本番順位とは比較しない。

調整に使用していない公式ジェネレータの seed 21,000,000〜21,000,099 では [22,122,939点](final-heldout-results.csv)、100件すべて完全可視・合法で両採点一致、最大2.823966秒。この集合では基準版を測っていない。別集合なので、配布100件の記録や目標達成判定に足さない。再生成は公式ツールで `seq 21000000 21000099 > seeds.txt` の後、`gen seeds.txt`。
