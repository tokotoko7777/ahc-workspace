# AHC008 late-seam candidate reuse

Comparator `seam-base.cpp` is an unchanged copy of area-priority GNU C++23 single-file `flex-speed.single.cpp`. `terminal-base.cpp` is an unchanged copy of the additional terminal-search branch. This cycle runs the actual isolated change on the area-priority comparator; it does not claim improvements on terminal, public practice, or system results.

The candidate is now integrated into the base late seam search, not a parallel project. A candidate can cross already-paid walls so only open portions have to be constructed; the bend policy additionally allows 45°/90° turns in short sequences. New cuts must still satisfy objective benefit and minimum retained area in the inherited exact flood-fill ranking. Every proposed build also requires an adjacent stance belonging to the retained component before selection. Existing late scheduler, evacuation logic, and cohesion repair are retained. The debug count is selections, not finished closures.
