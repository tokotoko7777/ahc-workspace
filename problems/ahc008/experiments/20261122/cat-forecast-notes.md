No official distributed IDs, final cases, editorials, or competitor submissions were used. All simulations used the official generator and tester. Cases are `in/` generated by `../ahc008_focus_assets/tools/target/release/gen seeds.txt`, with 100 unique Python MT-generated u64 seeds (seed-generation key 92485332). Training rows: 0–27 / 0–31. ## Exact Bayesian state

One normalized mass per target cell plus a no-target/reset sentinel. Walls are updated before processing the pet response. From the cat's origin, one forward BFS stores a shortest-path length and OR of shortest first-direction bits for each reached vertex. Removed, disconnected, and sentinel target mass is redistributed uniformly over reached cells other than the origin; the observed first action retains targets whose shortest first mask includes it and weights them by inverse mask cardinality. The second action chooses uniformly among unblocked neighbors independent of the latent target, so it has no extra filtering likelihood. Reaching the target at either intermediate or final cell moves its mass to the sentinel for the next observed turn. The random code used in rollout is internal simulation only, independent of the generator's hidden random seed.

`shortest-first-masks.hpp` and `cat-target-filter.hpp` are reusable, dependency-light helpers. `g++ -std=c++23 -O2 shortest-first-masks-test.cpp -o test-filter && ./test-filter` passed: brute reverse BFS masks and sequential filtering compared on 200 random wall maps. `cat-forecast.cpp` and the route successors inline both headers and compile without extra includes or optimized compiler flags (GNU C++23).

## Approximate uses and benchmarks

- Ray approach: calculate the four probabilities for the next directed step at each selection turn. Extend each direction up to fixed H cells (stop at a wall); use the mixture of baseline distance catch kernels from those four projected points, blended with the current position. This is approximate: the true target is not necessarily in the same cardinal direction for H turns.
- Route particles: 12 stratified draws from the posterior, each follows exact shortest direction selection with random second steps on the static current board over H turns, resampling target after each reset. Use projected occupancy in the midgame pocket catch kernel, or as an expected halving factor in proposed late-separator score. Actual construction alters walls, an important source of mismatch.
- Pocket mouth waiting: predict cat entrance through unbuilt perimeter cells of a nearly complete but empty pocket. Leave the most likely gap open briefly if modeled crossing probability exceeds .35, without changing earlier pocket selection. Trigger too rare to conclude benefit.
- Forecast CPU work respects the baseline's 1.65 s internal guard. Wall timings are observed during official simulation and include tester/process I/O; do not equate them to judge time.

### Negative alternative experiments and independent model diagnostic

`alternatives.csv` (20 development cases, baseline 309,501,729): larger earlier separators limited to root components with at least two cats and area at least 170 started at turn 170 or 188: -6.73% and -9.29%. Prioritizing currently buildable walls likely to become cat-blocked on the next turn: -20.10% (weight 10) and -12.01% (weight 22). Both rejected.

`forecast-metrics.txt`: on 18,900 baseline-trace directed first moves, conditional target posterior predicted the next step at 0.6944 nats/move negative log likelihood and 0.4348 summed multiclass Brier loss, versus 1.3820 nats and 0.7400 for treating the target as freshly uniform every turn. This checks predictive value, not control quality.

`final-fresh.csv` (28 fresh generator cases, no prior use): original 312,856,876; posterior ray5 367,164,764 (+17.36%); uniform-at-every-turn ray5 357,148,152 (+14.16%); lagged directed-move EMA ray5 388,459,805 (+24.17%); wait3 315,912,432 (~+0.98%, single changed case). The first two ablations separate geometric clipping of forecast rays from use of history. EMA update weights newest directed-step bit .47 and prior .53, adds .04 to each legal direction, renormalizes, and uses same H=5 / blend .65. Standalone no-dependency EMA candidate `cat-ema-lean.cpp` is generated by `python make-ema.py`; benchmark ablation source is `cat-ablation.cpp`. Strong development gain was sufficiently fragile to warrant another separate 60-case fresh generator set before recommending adoption.

`confirmation.csv`: separate fresh60 from `confirm/seeds.txt` (Python MT key 66766039), original 809,303,482, uniform-ray5 836,450,637 (+3.35%, 32/3/25), EMA-ray5 843,476,472 (+4.22%, 32/2/26). Paired case-bootstrap 95% EMA interval about [-14.3%, +26.4%]. Across fresh28 + confirmation60, EMA +9.78% with approximately [-6.1%,+28.9%] interval. Prefer optional retest against a stronger baseline; no default integration recommendation, particularly for the exact Bayesian rank. Tested byte-identical action traces between lean standalone EMA and ablation variant across the first four training cases.

Reproduce this ablation by building `cat-ablation.cpp` as `mod-ablation`, then running `python compare-alt.py 72 28 final-fresh-repro.csv original ray5 uniform5 ema5 wait3`. For the fresh60 set run `(cd confirm && ../../ahc008_focus_assets/tools/target/release/gen seeds.txt)` and then `python compare-confirm.py 0 60 confirmation-repro.csv original uniform5 ema5`. Use `cat-ema-lean.patch` to port the low-overhead EMA experiment; the full exact Bayesian code is not required for it.

`confirmation-wait-paired.csv`: on the independent fresh60, mouth wait3 scored 807,896,075 (-0.17%, 1 win / 58 ties / 1 loss, 56 matching action traces). Taken with the rare-trigger behavior and nominal earlier gains, not high-value enough to recommend default use. All official tester runs yielded 300 actions.

## Distinct projected-center follow-up
