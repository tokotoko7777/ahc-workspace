# AHC008: read-only central-aisle pocket screen

On 30 exact frozen v24 five-worker development replays (input, action and
official score checked against the existing independent replay), screen
adjacent tube rows sharing the middle aisle. Four already closed original
rails can make a three-cell pocket with two central-aisle gates. With only
three closed original rails, the fourth must be permanently retired; consider
a single off-rail plug for a two-cell pocket. Closing the aisle gates is
not allowed if it disconnects an available actual original tube stance,
any person, or either falls below 300 cells and 80% of initial exterior.
The screen also preserves already issued moves and wall commands.

Natural pockets were identified in 410 row×turn states. Only two eventual
leftovers (one input) were actually observed in a legal simultaneous gate
state, and no such state had two distinct ordinarily idle workers at
exterior distance ≤2. The new-plug class had 530 candidate geometry states,
three prospective visitors, zero theoretically legal closing states and zero
observed legal idle prep opportunities in the window. The disallowed class
that would retire an otherwise live original rail is reported separately.
Do not treat exposures as predictive causal changes under another policy.
A dot can be a reserved wait, so this staffing screen is permissive within
the action-preserving constraint. No live strategy changed or tested.

Original scripts retain the workspace and pinned development input paths.
See the [parent checkpoint](../v24-five-worker-rescue/README.md) for the
generator manifest and exact v24 source. The result CSV equivalent is
`dev30.json.gz`; `summarize.py` consumes the decompressed JSON.
