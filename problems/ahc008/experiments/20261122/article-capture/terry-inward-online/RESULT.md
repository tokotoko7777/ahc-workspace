# Moving one mouth inward: feasible in hindsight, rejected online

Screened the accepted incoming forecast's independently generated frozen
held100 tapes, not practice cases. Exact same-time physical closure
using one actor's actual prior wait had 545 compatible two-mouth rooms
and +568 summed mean scored cells, across 98 boards. Restricting to
cases where no animal can physically hit any *newly forbidden* endpoint
from t−1 (true passive step support, conservative directed 0–2) retained
324 rooms / 94 boards / +327 cells. Those screens knew which factual
room later closed, so are not proposed as implementable selectors.

The separate online observer uses only current stock ETA1 job, own
waiting/partner motion and local topology/reachable animal support
to select a single optional preparation. The independently confirmed
full command hashes and all 275 observed prefixes match in all 100
cases. Only after deciding, match the later factual same-role stock
closure. A verified match displaces one actual gate by one tile
without losing any immediate isolated pet ID, other work or existing
worker-reachable space at either affected turn.

The 78 confirmed closures preserve all compared IDs and gain total
78 mean-worker cells, but the frozen real-time match gate was ≥50%.
The unsupported preparation burden can already interfere with
factual immediate captures on unmatched states. Reject without
a new production controller or score test, no threshold/window tuning.
Passive support/gate counting and matched factual opportunities are
not guarantees of unobserved future trajectories.
