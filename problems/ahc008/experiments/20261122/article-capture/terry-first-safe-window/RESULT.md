# First individually safe capture opportunity: rejected at detached gate

Once a guard's estimated arrival is h=1,2,3, count the first
individually gate-safe endpoint in that animal's original room
over h..h+2, discounted by (h+1)/(hit+1). The physical walk still
uses projected walls whether inside or outside of the original
room. No control intentionally waits; this tests a different
short job weight only. Passive paths are exact; unchanged sampled
paths for dog and the original symmetric cat surrogate. The h-only
comparator uses the same affected animal components without later
hits. Three proposals always use the same crew, ties and sanitizer.
No alternative commands are applied.

The sparse uint64 per-pet reward and uint128 accumulator correctly
handle exact timing/overflow. All 300 random tree path enumerations
and deterministic fixtures match. The observer runs the accepted
retention afterward from a copied PCG state, verifying all raw
bins, accepted exact bins and final sample RNG are unchanged.
Across 60 previously verified generated recordings, every full
input/action/trace hash, original full score and all accepted
turn0..274 action prefixes match.

The sole witness is a rabbit in a three-cell one-mouth area: one
step after estimated arrival its old tape supplies a legal close
while the fixed other work survives. It is not causal. The
precommitted gate requires at least five across three boards,
so reject without real A/B or threshold/window tuning. This is
distinct from previous instantaneous own-gate screening and
trying to hold a job open for groups of animals. Reference score
unchanged.

Reproduce using the pinned private split predecessor, make.py,
GNU C++23 build and audit.py with the earlier fresh60 official tapes;
see PRESET. The independent helper and test + observer scripts are
bundled, without source containing private selector data.
