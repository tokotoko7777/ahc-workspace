# 保存済み2盤面を使った候補の組み換え

これは公式100ケースで以前に完走した **2つの盤面が既に手元にある**
条件の診断で、3秒以内に出せるソルバーの得点ではない。

片方をトーラス上で平行移動または転置して整列させ、差分セルごとに
どちらかの文字を選ぶ。各入力語の実現可能な置き場所を列挙して、
同じ語の全配置に関係する変数を一つの成分へつなぐ。成分が小さければ
全探索し、大きければ親A/B由来の2割当の良い方だけを使う。
収録語数が同じ場合は空白数を優先する。

- 公式・独立採点は100件すべて一致。高速化版6,998,515,279点、
  再構築版7,020,805,013点。各ケースで親の良い方を選ぶ値は7,035,180,846点で、
  組み換え後も同点。親の良い方を超えたケースは0。
- 異なる盤面68件中66件では差分セルがすべて一つの成分になった。
  整列後の全16,261差分セルのうち、各ケース最大成分に16,237セルが入った。
  広域の組み換えに向かず、既定探索には不採用。
- 3×3合成70件で差分セルの全割当と照合。実際に差が出たのは
  有望な組合せを含むように作った合成例で、公式100件とは区別する。

リポジトリルートから。入力と公式Rust採点器の入手方法は
[100ケースの比較記録](../README.md)。親Aと親Bは、それぞれ高速化版と
再構築版の計測が保存した `0000.txt` から `0099.txt` までの出力ディレクトリ。

```sh
E=problems/ahc004/experiments/local100/recombine
W=$(mktemp -d)
g++ -std=c++23 -O3 "$E/recombine.cpp" -o "$W/recombine"
python3 "$E/differential.py" "$W/recombine"
python3 "$E/audit.py" "$IN" "$PARENT_A" "$PARENT_B" "$VIS" "$W/audit" --recombine "$W/recombine"
```
