# Frozen AHC066 historical-case audit

Solver: default geometry templates at
`673d5843e9570e435a445d0a31df28cd58b81bcd`. No change after freezing and no
solver tuning or candidate selection from historical-case results.
The [manifest and results](official-audit-summary.json) are aggregate-only.

Use the official [published seeds](https://img.atcoder.jp/ahc066/seeds.txt)
untouched with the [standard tools](https://img.atcoder.jp/ahc066/O25rQjiK.zip)
from the [task](https://atcoder.jp/contests/ahc066/tasks/ahc066_a). The tool
ZIP SHA-256 is `a320640f3cf55504c29e1083e4c030cbcaf09fd681b42f10f2b21035a2011505`.
The [case archive](https://img.atcoder.jp/ahc_standings/ahc066/input.csv)
provides file ID, seed, N, M, T, and W. Stock case files directly expose
N/M/T, but W is the prior randomly drawn wall-segment count and is not
serialized. Run a private copy of the official generator with one
stderr-only diagnostic line immediately after the W draw. Do not adjust
the seed, generation logic, options for the stock run, data, or PRNG.
Require exactly matching W values and byte-for-byte matching case files
to prove the added diagnostic did not alter generated bytes. Only the
stock output goes to the solver. Do not redistribute the instrumented
official source or tool binaries.

Independently replay every legal solution with the official visualizer,
checking wall motion, recorded/replayed basic action sequence, swap effects,
both caps, and complete correctly sorted baskets. Wall time measures the
standalone solver (the official task is noninteractive). Positive raw
minima from the [official score matrix](https://img.atcoder.jp/ahc_standings/ahc066/result.csv)
are matched to account rank from [AtCoder results](https://atcoder.jp/contests/ahc066/results/json).
Compute round-to-nearest for each case with integers. Report both historical
minima and common minima including the candidate.

## Reproduce

Unzip the same official tool pack into two private directories. Build
`gen` and `vis` stock from the first directory with `cargo build --release --locked`.
Run the instrumentation script on the other copy's `tools/src/lib.rs`
and then build its `gen` with `cargo build --release --locked --bin gen`.
Set `GEN`, `TRACED`, `VIS`, `SEEDS`, `INPUTS`, and `SCORES` to these
binaries and archived data files.

```sh
p=problems/ahc066
python "$p/instrument_w.py" /path/to/private/copy/tools/src/lib.rs
# Build the instrumented gen here, before running below.
d=$(mktemp -d)
python scripts/bundle.py "$p/main.cpp" -o "$d/submission.cpp"
g++ -std=c++23 -O3 "$d/submission.cpp" -o "$d/solver"
python "$p/official-audit.py" "$SEEDS" "$INPUTS" "$SCORES" \
  "$GEN" "$TRACED" "$VIS" "$d/solver" "$d/work" \
  --freeze-id 673d5843e9570e435a445d0a31df28cd58b81bcd
```

Add `--prepare-only` to stop before executing the solver.
