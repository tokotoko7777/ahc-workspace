# AHC036

[公式問題](https://atcoder.jp/contests/ahc036/tasks/ahc036_a) /
[公式 Rust ジェネレータ・ビジュアライザ](https://img.atcoder.jp/ahc036/e5f02df53f30d36e.zip)。
配列 A の連続区間を B にコピーして青信号をまとめて作り、
指定された都市を順番に訪れます。

## 一要素ずつ更新する基準から、複数要素のコピーへ

両版とも各目的地への最短路を同じ BFS で作ります。基準版は、
必要な都市が B に入っていない時、その一要素だけをコピーし、
次に使う時点が最も遠い B の要素を上書きします。
固定経路と一要素更新の条件では、コピー回数の最適な置換です。

候補版は通過頻度の高い辺を優先し、各頂点を一度ずつ含むパス森を
構成して A に並べます。空き枠には、よく通るが配列上で離れている辺を
含む経路断片を複製します。次の都市を含むコピー窓を評価し、最良の
候補 8 個について B の全上書き位置を短い先読みで比較します。
まず青のまま連続して進める歩数を最大化し、その後の青を副指標にします。
基準案も完全に作って保持し、探索期限 2.45 秒を過ぎたら候補を破棄します。
これは追加探索で、等時間比較ではありません。

| 公式生成器の新規シード | 一要素の信号更新 | 連続区間コピー | 連続区間の勝ち |
|---|---:|---:|---:|
| 開発 12 件 | 65,381 | 23,451 | 12/12 |
| 凍結後・未調整 24 件 | 132,076 | 47,549 | 24/24 |

未調整の信号更新は 64.0% 減。移動回数は両版とも計 175,121 回。
全 72 実行で合法で、公式 `vis`・独立再生・C++ の数が一致。
候補版の最大操作数 11,289、CPU 7 固定の最大壁時間は 0.037 秒未満。
C++23 の提出用 1 ファイルは通常版と同じ 2,326 点を確認。
候補版が作業ブランチの既定で、`-DAHC036_SINGLETON` で基準版にできます。

## 本番比較

信号を書き換えた回数が絶対点で小さい方が良く、本番は 2,000 ケースで
`round(10^9×ケース別最小絶対点/自分の絶対点)` の和。非 AC は
相対点 0、最小値の計算から除外します。制限は 3 秒・1,024 MiB、
移動と信号書換の合計は 100,000 回以下です。

## 再現とライブラリ

公式 zip の SHA-256:
`6eb27811e0af9703ec36fc8bd44efdec110d1faa762161d4934d0a29d232944b`。
`cargo build --release --locked --bin gen --bin vis` で用意します。

```bash
bash problems/ahc036/run.sh build/ahc036 "$gen" "$vis" 7
```

既存の [`graph_bfs`](../../library/graph-bfs.hpp) は経路復元に利用。
[`Dsu`](../../library/dsu.hpp) は閉路を検知できますが、次数の上限と
各成分の両端からの復元は自前で必要だったため、
[`greedy_path_forest`](../../library/greedy-path-forest.hpp) として切り出し。
[使用例](../../examples/greedy_path_forest_usage.cpp) と
[愚直な連結性判定との 1,200 件の比較](../../tests/greedy_path_forest_test.cpp)
を付けました。次は経路を固定せず、現在の B だけで到達できる連結成分と
まとまった A の区間を経由する経路を探索して、多少歩数が増えても
新しいコピーが少ない経路を選びます。
