# AHC071

[公式問題](https://atcoder.jp/contests/ahc071/tasks/ahc071_a) /
[公式 Rust ジェネレータ・ビジュアライザ](https://img.atcoder.jp/ahc071/Wfu7FwbO.zip)。
幅 60、高さ 40 の壁の穴 120 個を、中央だけを下から支えるレンガで覆います。

## 一行ずつから、支えを含む二行同時 DP へ

対照は上から一行ずつ進み、その行の穴と直上のレンガ中心を
覆う最安の非重複区間を左からの DP で決めます。置いたレンガの
中心だけを次行の必須セルに足すため、全段の支持が保証されます。

候補は上下二行を同時に左から処理します。状態は、上段レンガの
残り幅と中央までの残り、下段の残り幅。いまの列が上段レンガの
中央なら同じ列の下段が覆われる制約を加え、二行の合計費用を厳密に
最小化します。下段の中央を次ブロックの要求にします。
二行の切り方を上下に一段ずらした二通りと、一行版から最安を選びます。
追加 DP があるため等時間比較ではありません。
幅 1〜9 の 1,200 個のランダムな二行を、独立した全列挙と比較しました。

| 独立シード | 一行 DP の公式点 | 二行 DP の公式点 | 費用（一行 → 二行） | 勝・負・同 |
|---|---:|---:|---:|---:|
| 開発 14 件 | 137,662 | 144,016 | 30,352 → 23,998 | 14・0・0 |
| 凍結後・未調整 28 件 | 279,034 | 290,702 | 56,994 → 45,326 | 27・0・1 |

未調整の費用は 20.47% 減、公式点は 4.18% 増でした。
既定は二行版、`-DAHC071_ONE_ROW` で一行版です。
全 84 実行で穴の被覆・重複・中央の支持を独立検査し、
公式 `vis` と C++ の費用・得点が一致しました。CPU 7 固定で最大
0.009 秒未満。単一ファイル C++23 も 10,354 点で通常版と出力一致です。

既存の DP 補助は反復状態に「残幅」と「中央の列」を載せる遷移を
用意していないため、二行の転送表は問題側に実装し、汎用化していません。
次は既存配置の上下を固定したまま隣接二行を置き直し、
初回に使わなかった組み合わせで費用が落ちるか試します。

## 本番比較

公式点は `max(0, W*H*c1−費用+1)`、本番 150 ケースの和を最大化。
2 秒・1,024 MiB、不正や時間超過が一つでもあれば提出全体が 0 点です。
終了後のシステムテストはなし。
[公式結果](https://atcoder.jp/contests/ahc071/results/json)の 1 位は rhoo。
点数は載っておらず、[得点 CSV](https://img.atcoder.jp/ahc_standings/ahc071/result.csv)・
[入力対応表](https://img.atcoder.jp/ahc_standings/ahc071/input.csv)は HTTP 403。
同梱 100 種を本番 150 件と同じとは確認できないため **未判定** です。
外部の解説・他の提出は使っていません。
