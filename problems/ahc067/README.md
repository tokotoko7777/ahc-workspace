# AHC067

[公式問題](https://atcoder.jp/contests/ahc067/tasks/ahc067_a) /
[公式 Rust ビジュアライザ・ジェネレータ](https://img.atcoder.jp/ahc067/BpPfrS30.zip)。
扉とスイッチを設置し、入口から玉座まで到達可能なまま、
勇者の最短行動数を大きくします。

## 橋の間に、必須の寄り道を作る

対照は、現在の最短路上にある橋でない辺を候補に、
永久に閉じる扉（スイッチを置かない種類）を一つずつ選びます。
最短路を最も延ばす候補を選び、同点は乱数で崩します。
両方式とも上限 7 回、同じ乱数列から始めます。

候補は閉鎖が最大 41 本の中間グラフで、玉座へ行く際に必ず渡る
橋を入口側から並べます。選んだ各橋に独立した初期閉扉を置き、
ひとつ前に選んだ橋を渡った後、今回の橋を渡る前にしか行けない
区間にスイッチを置きます。区間を分けるのも橋なので、
以前の区間から先回りして押したり、他の経路から次の区間へ
行ったりできません。各区間の最短寄り道は
「区間入口→スイッチ→扉」の距離和−直接距離に押下 1 手を
足して算出でき、どの橋を選ぶかは区間 DP で最適化します。
同じ試行で静的閉鎖を最大 50 本まで進め、その対照も候補として残します。
追加 DP の分、同時間比較ではありません。

| 独立シード | 静的閉鎖の公式点 | 橋と寄り道の公式点 | 最短手数の和（静的 → 寄り道） | 寄り道の勝ち |
|---|---:|---:|---:|---:|
| 開発 14 件 | 34,425,446 | 50,599,856 | 1,570 → 3,434 | 14/14 |
| 凍結後・未調整 28 件 | 63,940,985 | 100,997,213 | 2,792 → 6,834 | 28/28 |

未調整の得点は 57.95% 増。初回の寄り道版は `-DAHC067_NO_EXCHANGE`、
`-DAHC067_STATIC` で静的閉鎖版です。
全 84 実行で公式 `vis`、独立の「頂点・押下の偶奇」BFS、
C++ の最短手数・公式点が一致。CPU 7 固定で最大 0.041 秒未満。
単一ファイル C++23 の出力も通常版と一致し、3,649,615 点でした。

既存の有向 SCC は無向辺の橋を返さないため、
[無向グラフの橋](../../library/undirected-bridges.hpp)を追加しました。
[使い方](../../docs/LIBRARY_REFERENCE.md#undirected-bridges)と、
[2,500 グラフで各辺を独立除去するテスト](../../tests/undirected_bridges_test.cpp)
で、平行辺・自己ループも確認しました。問題固有の区間 DP は分離しています。

## 本番比較

到達可能なら `round(10^6 log2(T/N))`、不可能なら 1 点。最大化です。
2 秒・1,024 MiB、本番は 150 ケースの和で終了後テストはなし。
一つでも不正・時間超過なら提出全体が 0 点です。
[公式結果](https://atcoder.jp/contests/ahc067/results/json)で 1 位は
udon1206 ですが数値は載っていません。
[公式得点 CSV](https://img.atcoder.jp/ahc_standings/ahc067/result.csv)・
[入力対応表](https://img.atcoder.jp/ahc_standings/ahc067/input.csv)は HTTP 403。
公式工具に同梱の 100 種と本番 150 件の同一性が確認できず、
1 位比較は **未判定** です。他の解説・提出は使っていません。

## 追加実験: 閉鎖配置を、必須の寄り道に合わせて交換

まず初回版と同じ妥当な配置を確保します。閉じた辺を一つ開き、
別の橋でない辺を閉じる提案を上限 36 回試します。
現在の最短路にある候補を優先しつつ、最短路以外も調べます。
双方とも同じ提案生成とゲート DP を用いますが、次の提案開始点と
するかどうかは、対照がスイッチなしの距離、候補がスイッチ込み
の最短手数で決めます。どちらも出力には、訪れた配置の中で
公式最短手数が最長のもの（初回版を含む）を残します。

| 新規独立シード | 静的距離で受理 | 寄り道込みで受理 | 勝・負・同 |
|---|---:|---:|---:|
| 開発 14 件 | 51,688,737 | 52,149,923 | 8・4・2 |
| 凍結後・未調整 28 件 | 103,218,534 | 103,367,464 | 14・11・3 |

同予算の二方式の差は未調整で +0.14% と小さく、
改善幅上位二件を除くと逆転するため、受理基準単独での優位は
強くありません。一方で交換なしの初回版と比べると、
同じ 28 件が 100,794,511 → 103,367,464（+2.55%、27 勝・1 同）、
最短手数の和は 6,800 → 7,248 でした。
追加版を既定に採用し、`-DAHC067_SWAP_STATIC` で同予算対照、
`-DAHC067_NO_EXCHANGE` で交換なし版を再現できます。
両比較の全 168 実行は公式・独立 parity BFS・C++ で一致し、
CPU 7 固定で両方式とも最大 0.297 秒未満でした。
単一ファイル C++23 の試走は 3,661,065 点、出力も同じです。

```bash
bash problems/ahc067/run_exchange.sh build/ahc067-exchange "$gen" "$vis" 7
```

一辺の交換では越えられない橋区間の組み換えを試します。
本番 1 位比較は引き続き未判定です。
