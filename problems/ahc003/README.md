# AHC003

[問題文・公式ローカルテスタ](https://atcoder.jp/contests/ahc003/tasks/ahc003_a)

**比較の目安は未達で、現在の版を保存しています。** 道路の長さと分割位置を、経路に対する応答から逐次推定します。
各線で一定の長さと途中で変化する長さを比較し、分割位置の再推定、各辺の補正、ばらつきの推定を組み合わせています。
`main.cpp` は専用ヘッダを結合済みの、独立に作成した単独のC++17ファイルです。

```sh
g++ -O3 -std=c++17 main.cpp -o solver
./tools/target/release/tester input.txt ./solver
```

公式ツールの展開先に応じて、`tester` のパスを変更してください。
対話型なので、公式の隠し入力ファイルをそのまま `./solver` にリダイレクトして実行する形式ではありません。

同じ実行ファイルで、本番シード先頭30件は平均 **974,119,045.07点**、
未使用の公式生成器seed 20000〜20019は平均 **974,473,661.40点**でした。
合計50件の平均は **974,260,891.60点**、最大時間1.23479秒。
全50件の各1,000応答で、独立した検証と公式テスタの得点が一致しました。

1位の全3,000件平均975,589,247.8123点には、簡易比較でも約133万点届いていません。
1位の同じ50件の得点とは直接比較できておらず、本番順位を確定する結果ではありません。
本番30件は改善にも使用し、追加20件は版と評価計画を固定してから初めて測定しました。
