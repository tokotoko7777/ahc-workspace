# AHC063

[公式問題](https://atcoder.jp/contests/ahc063/tasks/ahc063_a) /
[公式 Rust ジェネレータ・ビジュアライザ](https://img.atcoder.jp/ahc063/EbfTtMTp.zip)。
移動するヘビで次の希望色を食べ、食べられないときでも
短い実行時間で合法な近似列を返します。

## 動く尾が空ける通路

基準は今の胴体を壁とした BFS で最寄りの食べ物を探し、
次の希望色が取れるなら優先します。着く前に別の色は通過しません。
希望色が静的 BFS で届かない場合だけ、候補は
`(経過手数, 座標, 進入方向)` を状態にした最大 15 手の探索を加えます。
食べずに移動を続ける場合、現在の胴体の各セルが空く最短の手数が
わかるので、時間が来てから通れるセルも探索します。
経路自身が作る胴体までは BFS の状態に含めず、取れた経路を
ヘビの全状態で再生し、道中の食べ物・噛み切り・逆走がない経路だけを使います。
合法性はこの再生で保証しますが、圧縮した BFS はすべての経路は列挙しません。
両方式とも同じ 12 再始動と初期乱数列、最良の有効な出力を残します。
追加 BFS があるため等 CPU 時間の比較ではありません。

| 独立シード | 静的 BFS の絶対費用 | 尾の解放時刻あり | 勝・負・同 |
|---|---:|---:|---:|
| 開発 14 件 | 5,514,438 | 5,274,062 | 8・4・2 |
| 凍結後・未調整 28 件 | 7,018,745 | 6,639,383 | 15・9・4 |

未調整の費用は 5.41% 減、完全一致のケースは 4 → 6。
初回の尾解放版は `-DAHC063_NO_BRANCH`、静的対照は `-DAHC063_STATIC` です。
全 84 実行で公式 `vis`、独立の座標・食べ物・切断の再生、
C++ の絶対費用が一致しました。CPU 7 固定で最大 0.009 秒未満。
通常版と単一ファイル C++23 は同じ出力で 20,584 点でした。
[リプレイの回帰テスト](../../tests/test_ahc063_replay.py)は
胴体への衝突と尾だけの重複が違うことも検査します。

既存の `grid-bfs.hpp` は位置だけの探索で、尾が空く時刻・進入方向・
食べ物上での探索終了を同時に扱えないため、問題側に配列探索を
手書きしました。経路の胴体再生と密結合のため汎用化は見送りました。

## 本番比較

絶対費用は `T + 10000 (E + 2(M-k))` の最小化。
本番の相対順位点は共通参加者数を分母とし、各ケースで小さい
絶対費用の人数と同点の半数から
`round(10^9 * (1-(n_lose+0.5*n_tie)/n_submit))` を計算します。
本番 2,000 ケースの和、2 秒・1,024 MiB、無効ケースの順位点は 0。
[公式結果](https://atcoder.jp/contests/ahc063/results/json)と

[公式得点 CSV](https://img.atcoder.jp/ahc_standings/ahc063/result.csv)
（`rank_min,1e9`、1,264 人×2,000 ケース）から、
rhoo の本番 1 位 **1,985,255,142,455 点**を再計算しました。
[入力対応表](https://img.atcoder.jp/ahc_standings/ahc063/input.csv)の種は
[公式本番種](https://img.atcoder.jp/ahc063/seeds.txt)と順序まで一致しています。
本番種 SHA-256 は
`daf8cb67f5deb3bcb35e3d34b97a3b7b7a3ee8da1fe1cbe24f39389ad64a6c85`。
初回は本番未実行でした。追加版の本番比較は下の凍結監査に記録します。
外部の解法や他の提出は使っていません。

## 追加実験: 次の色まで通れる取り方を選ぶ

現在の希望色を取れる近い経路を最大 4 本保持し、それぞれを
実際の胴体・食べ物・色列へ適用します。その到着状態を起点に
同じ静的 BFS を 1 回ずつ行います。対照は「次に何色でも取れる」経路、
候補は「次の希望色が取れる」経路を優先します。
評価は初手の長さ・次の経路長・次の色の可否で、同じ探索・再始動上限です。

| 独立シード | 次色なしの出口評価 | 次色を評価 | 勝・負・同 |
|---|---:|---:|---:|
| 開発 14 件 | 4,944,211 | 4,924,456 | 9・5・0 |
| 凍結後・未調整 28 件 | 9,249,104 | 8,289,603 | 16・12・0 |

未調整の費用 10.37% 減。追加探索なしの初回版と比べても、
同じ未調整 28 件が 9,058,369 → 8,289,603（8.49% 減、15・12・1）
で、改善幅の上位 2 件を除いても 218,601 改善しました。
完全一致は初回版の 3 から 2 に低下しており、全ケースに有利ではありません。
追加候補を既定に採用し、`-DAHC063_ROUTE_CONTROL` で同予算対照、
`-DAHC063_NO_BRANCH` で初回の尾解放版を再現できます。
二つの比較で全 168 実行が公式・独立・C++ と一致しました。
CPU 7 固定で最大 0.060 秒未満です。
単一ファイル版の試走は 50,380 点で通常版と同じ出力でした。

```bash
bash problems/ahc063/run_routes.sh build/ahc063-routes "$gen" "$vis" 7
```

次に、希望色に届かないときは色違いを維持するだけでなく、
間違った末尾だけを自ら切り落とし、正しい接頭辞を復元できる
短い修復経路を別近傍として試します。

## 本番 2,000 件の凍結監査

次色あり既定版の `11694896c41ef8d95b305d019db001f47e640c1d` を
凍結し、公式公開種を変更せず公式ジェネレータへ渡しました。
入力対応表の種の順序・ファイル名・`N,M,C` が 2,000 件で一致。
公式順位点の種別・係数・人数と、公式 1 位の順位点を確認してから
候補を実行しました。公式ツール・独立再生・C++ 費用を全件照合し、
本番ケース別結果を使った調整は行いません。

履歴固定では、履歴の各参加者は同点の中から自分だけを除き、
凍結版は履歴外なので履歴内の同じ費用を全て同点として数えます。
全員の公式順位点を同じ分母 1,265 人で比べる仮追加の比較では、
双方の点数をその共通順位分布から再計算します。
無効ケースは順位点 0 で、人数の分母には含めます。

```bash
bash problems/ahc063/run_official_audit.sh build/ahc063-official \
    "$gen" "$vis" "$seeds" "$input_csv" "$result_csv" 7
```

公式ファイル、凍結ソースと単一ファイルの SHA-256 を検査します。
公式への再提出ではなく、同じ本番入力を用いたローカル再現です。

| 比較集団 | 公式 1 位 rhoo | 凍結版 | 比較 |
|---|---:|---:|---|
| 履歴 1,264 人の分布を固定 | 1,985,255,142,455 | 1,189,793,908,234 | 495 位相当、同点なし |
| 凍結版を加えた 1,265 人で双方再計算 | 1,985,266,007,770 | 1,190,434,387,385 | 495 位相当、同点なし |

全 2,000 件が合法で 3 方式の費用が一致。絶対費用の合計 586,403,135、
希望色列の完全一致は 362 件、CPU 7 固定で最大 0.111 秒未満。
共通集団で 1 位との差は 794,831,620,385 点で **未達** です。
凍結した C++23 単一ファイルの SHA-256 は
`eefb7845768a5a1ca23661318e0209e2bc5ffa8a66c4734ca1bfe96d9f67a552`。
